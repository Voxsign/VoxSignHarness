## 一、项目一句话
VoxSign Harness = **个人生产底座**（不是软件产品）：语音控制电脑，Go 单二进制、模型驱动、先自用。目标：让"下次同类任务少解释、少操作、少犯错"，10 倍效率来自底座复利。

## 二、已定设计哲学（讨论沉淀，不再重议）
1. **认识/执行分离**：认知层（文字/模型/慢变）｜接口层（契约/版本化）｜执行层（代码/快/确定）；边界=契约
2. **三层生长 + 生长回路**：认知层生长（画脑袋）· 契约层生长（只增不改+supersede 归档）· 工具层生长；生长回路=Use→Gap→Triage→Draft→Verify→Register→Pilot→Learn→Benefit
3. **分配原则**：凡显性化/标准化→用基础设施（模型调用/ASR/权限/协议）；凡个性化→自建服务（认知/词典/OGSM/工具面）
4. **冻结边界、一次只动一层**：契约/权限策略打版本冻结，后续只增不改
5. **北极星指标**：每个合格结果消耗多少分钟人工注意力（非延迟/token/功能数）
6. **归因六格**：输入/上下文/契约/模型判断/执行/外部——不是"模型错 vs 执行错"两格

## 三、V0 现状（技术底座已验证）
- M1 完成：Go 单二进制 1.6MB、五平台交叉编译、启动 16.1ms、输入容错管线 9.9µs、轨迹 JSONL append-only、10 包测试全绿
- 硬验收演示跑通：`"帮我打开美墅的文件夹看看有什么"` → 词典纠错（美墅→Mansour）→ 意图 JSON(FILE_LIST) → 执行 → 回执 → 轨迹可回溯
- V0 闭环目标：**"记一条 → 回问确认 Mansour → 写入本地存回执 → 下次不再问"**，约 2-3 千行 Go，两周
- 模型中心通道全通：基础层 4 模型 + /v1/codex（gpt-6-astra）+ /v1/cursor（gpt-5.2）+ /v1/claude（claude-sonnet-5，本轮已修复验证）

## 四、已有评审意见（如实汇总）
**研究引擎（gpt-6-astra，VS-HARNESS-001）**：北极星指标如上；错误也会复利，须内置纠错/撤销/淘汰；最危险失败模式="为了高效，先给自己造了个永久维护项目"；"你可能把方法论一致性当成了需求已验证的证据"。

**基础层 gpt-4o / gpt-4o-mini**：归因六格最扎实、轨迹重放可靠；get_time 该砍；生长回路状态机过复杂；最大缺口=外部反馈机制。

**Codex（gpt-6-astra）**：可行但"闭环成立≠生产可用"；最大坑=把一次确认固化为永久真相——"永不再问"必须限定仓库/分支/版本/权限；**回执只证明执行，不能代替验证**；REVIEWER 必须独立读原始证据+有否决权；用相同任务对比单工模式，赢不了就是付费仪式感。

**Cursor（gpt-5.2）**：可行但"仅勉强可上线"；最大坑=确认摩擦+语音不确定性叠加（频繁打断→弃用；少确认→错记→不信任）；receipt 必须可检索/可追溯/可撤销，"不再问"做**条件化规则**（仅同类上下文生效）；**确认策略引擎**：风险/置信度阈值+抽样复核，低风险自动、高风险强确认，避免"每步都问"；三 OPC 真收益只来自硬闸门（测试/diff/回滚/预算），不是角色命名。
