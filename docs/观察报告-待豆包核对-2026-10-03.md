**现象**
```
POST /v1/run {"text":"实现《VoiceSign个性化ASR后台需求说明书v2》"}

    "role":"","status":"waiting_confirm","task_id":"task-…"}

```

**复现**
```bash

  --data-binary '{"text":"实现《VoiceSign个性化ASR后台需求说明书v2》"}' | python3 -c 'import json,sys;print(json.load(sys.stdin)["task_id"])')
```
