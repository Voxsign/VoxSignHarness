### OBS-01 【真跑】`waiting_confirm` 的响应**缺 `attribution` 与 `receipt`**

**现象**
```

⇒ 任务停在 waiting_confirm，响应**只有 4 个键**：

    "role":"","status":"waiting_confirm","task_id":"task-…"}

```

**复现**
```bash

  --data-binary '{"text":"实现《VoiceSign个性化ASR后台需求说明书v2》"}' | python3 -c 'import json,sys;print(json.load(sys.stdin)["task_id"])')
```

**已排除**
- 不是"任务太慢还没填"：**3s / 8s / 15s 三次响应完全一致**

**严重度**：中（信息量不对称；影响所有需要人介入的 UI/自动化）

### OBS-09 【真跑】⭐ `/v1/run` 的 `role` 为空，`/v1/tasks` 的为 `verifier`（**同根因的第三个症状**）

**⚠️ 我未核**：`handleRun` 是否**有意**不设初始角色；role 为空是否影响下游角色推进
