**盲评抓到的真问题**（不是我自查发现的）：
- `llmIntentFallback` 会清空 `Ask` → **绕过「Ask≠'' → 绝不执行」这条安全红线**（同类缺口**连踩三次**）
- `请勿删除` / `无需提交` / `不再部署` 全漏 → G1 **根本没闭合**
- 我用"字数"判元指令，**漏判和误判两个方向都错**

## 4. 一条贯穿全程的模式（**六次**）

```
① rubric-v0         把「更安全的行为」判成违规
② asr-split-punct   把「产品口径」当「系统缺陷」
③ C1 v1             把「正文」与「标点」写进同一判据
④ C1 v2             把两类改动塞进同一个 Corrections
```
