# 个性化后台实现-实现计划

## 1. 项目目标

构建一个**独立运行的 Go 后台服务**，实现 ASR 识别文本的**个性化纠错与学习闭环**：

- 用户教过的词 → 记入词典（dictionary）
- 用户标错的词 → 记入黑名单（blacklist）
- 用户确认过的映射 → 记入反馈（feedback）

服务需在后续纠错中应用这些数据，实现"越来越懂你"的持续学习效果。

## 2. 技术约束

| 约束项 | 要求 |
|---|---|
| 语言与依赖 | Go 语言，**仅标准库，零第三方依赖** |
| 运行方式 | **可独立运行**；通过 flag 或环境变量配置监听地址（默认 `127.0.0.1`）与数据目录（默认 `./data`） |
| 数据持久化 | feedback 用 **JSONL append-only**；dictionary / blacklist 用 JSON 文件 |
| 代码质量 | **不留 TODO / 占位 / 伪代码**，自包含，可直接 `go build` 通过 |
| 文本处理 | 中文文本处理，UTF-8 编码 |

## 3. P0 能力清单

以下能力**全部必须实现，逐条验收**：

| # | 端点 | 行为 | 数据文件 |
|---|---|---|---|
| 1 | `GET /v1/health` | 健康检查 → `{"ok":true}` | 无 |
| 2 | `GET /v1/dict` | 返回全量词典 JSON（terms 数组：term / variants / category / source） | dictionary.json |
| 3 | `POST /v1/term` | 增词（body：term / variants / source），写回词典并持久化 | dictionary.json |
| 4 | `POST /v1/correct` | 个性化纠错：输入 `{text}`，应用词典映射（如 曼苏→Mansour）与黑名单拦截，返回 `{corrected, applied:[…]}` | 读 dictionary / blacklist |
| 5 | `POST /v1/process` | 意图分类 + 纠错：输入 `{text}`，返回 `{intent, corrected}`（intent ∈ NOTE / QUERY / EDIT / …，含纠错结果） | 读 dictionary / blacklist |
| 6 | `POST /v1/feedback` | 反馈学习：输入 `{raw, corrected, accepted, reason}`，**追加** feedback.jsonl（append-only；`accepted=false` ✘ 时必带 reason） | feedback.jsonl |
| 7 | `POST /v1/blacklist` | 黑名单：输入 `{term, note}`，写入 blacklist.json（"这个改错了" → 纠错时跳过该词） | blacklist.json |
| 8 | 鉴权（可选） | 环境变量配置 token 时，校验请求头 `Authorization: Bearer <token>`；未配置则关闭鉴权 | 无 |

## 4. 数据持久化设计

- **dictionary.json**：存储词典词条，字段包含 term、variants、category、source；由 `GET /v1/dict` 读取、`POST /v1/term` 写入。
- **blacklist.json**：存储黑名单词条，字段包含 term、note；由 `POST /v1/blacklist` 写入，纠错时跳过命中词。
- **feedback.jsonl**：追加式（append-only）记录反馈，字段包含 raw、corrected、accepted、reason；由 `POST /v1/feedback` 追加。
- 所有数据文件落盘于数据目录（默认 `./data`），**需跨服务重启保留**。

## 5. 验收判据（真装配，不许桩）

1. `go build` 零错误（仅标准库）。
2. 服务启动后 `GET /v1/health` 返回 `{"ok":true}`。
3. `POST /v1/correct {"text":"你好 曼苏"}` → corrected 中含 `Mansour`（词典生效）。
4. `POST /v1/feedback` 后，`data/feedback.jsonl` **追加**一条记录（含 raw / corrected / accepted / reason）。
5. `POST /v1/term {"term":"Mansour","variants":["曼苏"]}` 后，`data/dictionary.json` 含该词条（持久化）。
6. 重启服务后，词典 / 黑名单仍在（持久化跨重启）。
7. 所有端点返回 JSON 响应，中文不乱码。
