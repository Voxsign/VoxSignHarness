# VoxSign iOS UI 重设计任务书（99% 复制豆包）

## 你的角色
你是资深 iOS 移动端 UI/UX 设计师，特别擅长把主流 App（豆包）的界面语言精确复刻到同类产品上。**用户明确要求：移动端界面 99% 复制豆包 App，不要任何创新装饰。**

## 产品背景
VoxSign 是一个"语音控制电脑"的助手 App：用户在手机上按住说话，后台 Harness（电脑端代理）执行任务（整理文件、查日程、翻译、跑代码等），结果以对话形式回到手机。App 有"云道（官方云端，Google 登录即用）"和"自建（用户自己添加 Harness 服务器）"两种连接模式。

## 设计铁律（用户原话转述，必须遵守）
1. **99% 复制豆包 iOS App**：顶栏极简克制、白/浅灰底、会话流圆角气泡、底部输入区胶囊感。不要渐变 Logo 大块、不要状态徽标堆砌、不要花哨空态欢迎屏、不要任何"设计师自我发挥"。
2. 语音交互完全豆包式：**按住说话、上滑取消、松开发送**，录音时顶部出现语音状态条。
3. 所有按钮、手势、文案都要有真实交互反馈（高保真可点击原型）。

## 必须覆盖的页面（全部做成可交互高保真原型）
一个单文件 HTML，内嵌多个 iPhone 画框或页内切换，包含以下全部页面/状态：

### A. 主页 / 会话页（核心）
1. **顶栏（豆包式极简）**：左侧连接状态胶囊（绿=在线/黄=重连/灰=离线，极小的圆点+文字，不抢视觉）；中间 VoxSign 标题（普通黑色粗体即可，不要渐变字）；右侧设置齿轮。
2. **空态**：无对话时显示一句克制的中性提示（如"说点什么，或按住下方按钮说话"），**不要**大 Logo、不要示例建议卡片堆。
3. **对话流**：用户语音消息=右侧蓝紫色渐变气泡（豆包同款，含小声波）；AI 回复=左侧白色气泡（圆角，无阴影或极轻阴影）；AI 思考中=左侧"三点动画+文案"；任务回执=左侧气泡带"已处理 X.X 秒"小字 + 下方"可撤销"小按钮（44pt 命中区）。气泡圆角：用户 18/18/4/18（右下小角），AI 18/4/18/18（左下小角）——豆包同款不对称圆角。
4. **决策点（确认/问询）**：AI 需要用户确认时，会话流下方出现卡片：确认（问题文字 + "执行"蓝按钮 + "取消"灰按钮）；问询（问题 + 多个候选选项按钮）。豆包式浅色卡片，无重阴影。
5. **打断条**：检测到"停止"类意图时，输入区上方出现红色系统条（可关闭，带"停止并撤回"按钮）。
6. **输入条（豆包式，最重要）**：
   - 默认语音模式：左侧键盘图标（切打字）+ 右侧大圆形语音按钮（蓝紫渐变；按住立即变红呼吸）。
   - 按住说话：顶部出现红色语音状态条："正在听…" + "松开 发送 · 上滑取消"；3 秒无声音变"没听到声音，请说话"（橙条）；松手=自动发送；上滑（-80pt）=取消。
   - 识别后（平台校准中）蓝条"正在校准…识别完成后自动发送"；识别失败橙条"识别失败，请再按一次"。
   - 打字模式：胶囊输入框"说点什么，或打字…" + 蓝色圆形发送键。
   - 输入条整体：半透明毛玻璃底，极简。

### B. 设置页（iOS 原生 Form 风格，彻底豆包/微信式，不用花哨卡片）
1. **连接模式分段**：云道 · 默认 / 自建。
2. **云道页**：未登录=居中 Google 官方四色 Logo 按钮"使用 Google 登录"+ 一行说明；已登录=头像/邮箱/档位(Prime)/今日额度/体验会员到期日 + "刷新登录态"+"退出登录"（iOS 表单行）。
3. **自建页**：空态="还没有自建服务器" + "添加服务器"按钮；列表=服务器行（圆点选中态/名称/地址/机器码·云端转发小标签/当前标记，左滑删除）；点击进入编辑（名称/地址/Token/绑定标识 + "测试连接"/"立即重探"）。
4. **添加服务器弹层（底部 sheet）**：两种方式——"IP 地址"（输入名称/地址/Token；检测到内网地址自动出现"通过云端转发访问"开关；"保存并检测连接"按钮+检测中状态+错误提示）/ "机器码"（输入机器码→"查询并绑定"→展示机器名/地址/连接方式(同网直连或云道转发)→"保存"）。
5. **连接状态 section**：圆点+已连接/正在重连…/离线 + 最近错误小字。
6. **语音朗读 section**：朗读回复开关 + 语速滑块(0.40-0.60) + "试听"按钮。
7. **后台能力 section**："补投离线队列"按钮 + 队列数/通知授权状态小字。

### C. 未来预留（只在说明中标注，不占界面）
harness 状态徽标（idle/busy/decision）与意图识别联动（"停/撤/优先/确认"语音指令 → interrupt/withdraw/priority 接口）——服务端已就绪，iOS 待做。原型里顶栏可放一个极小的空闲/处理中状态点作为预留位，但要与豆包顶栏风格一致。
