## 1. 这个项目是什么

**voice-sign-harness（`vhs`）**：一个 Go 单二进制、**零第三方依赖**的语音驱动开发 harness。

```
语音 → ASR 文本 → [纠错/标点] → 意图 → 规划 → 域门禁 → 执行 → 独立校验 → 回执
```

**核心红线**：`Ask != '' → 绝不执行`；**域=权限交集，默认拒绝**；**不可逆必须人工确认**。

**已外接三个服务**（都在 `aiops.peterzou.com` 后面，**一把 key**）：

| 服务 | 用途 | 状态 |
|---|---|---|
| AIOps 网关 | `/api/summary` `/api/services` `/api/hosts` `/api/route` | ✅ |
| JEV `/api/decide` | **快判断**（L0.5 层） | ✅ 实测 5 组用例通过 |
| 知己 `/api/zhiji/api/*` | **长期记忆** | ⚠️ **只读**（`read_only:true`），`distill` 端点 404 |

## 4. 工作方法（**这是这个项目最重要的资产**）

### 4.1 自举闭环（`docs/技能-自举闭环工作法-v1.md`）

```

```

### 4.2 角色分工（**不许混**）

| 角色 | 做什么 |
|---|---|
| **DSH / 设计方** | 文档、判据、语料、评测、盲评。**不写 `asr/` 实现代码** |
| **实现方** | 按判据实现、真跑、报看板 |
| **测试方** | 立判据（判据归它）、不许实现方改判据 |
| **校验方** | 一致性比对、异源盲评（只读规格+代码，不读汇报） |

### 4.3 ⭐ 9 条「等价是假设，不是事实」（**最耐用的一页**）

| # | 看起来等价 | 真跑暴露 |
|---|---|---|
| 1 | 有 `defer Unlock` ⇒ 安全 | `unlock of unlocked mutex` |
| 2 | 滑窗+编辑距离单遍 ⇒ 够用 | **吃前缀**（`把爱ops接上`→`aiops`） |
| 3 | 库层全绿 ⇒ K9 完成 | **HTTP 路径根本没接** |
| 4 | httptest 同构 ⇒ main.go 可行 | **真进程路径未验证** |
| 5 | fake 判据全绿 ⇒ 解析正确 | **真端点带尾随字节** |
| 6 | `push` 说 up-to-date ⇒ 交付成功 | **commit 根本没发生** |
| 7 | `red=0` ⇒ 健康 | **包没编译**（`pass=0`） |
| 8 | 补丁打完 ⇒ 改好了 | **静默没生效**（grep 才发现） |
| 9 | **能编译 ⇒ 能通过** | **判据红着被推出去** |

> **规律**：**凡是"看起来等价"的地方，都要回读一次。等价是假设，不是事实。**
> **机制强度：类型 > CI > hook > 文档。**

### 4.4 三条"标了适用条件的绿判据"（**惯例，请沿用**）

| 例 | 标的是什么 |
|---|---|
| `WM-1` | "**在什么口径下**成立"（依赖 `DemandFloor` 推断） |
| `SCOPE-PROFILE-01b` | "**将来**才可能被触发"（前瞻守卫 `forward-guard`） |
| `ASR-EXEC-05` v2 | "**现在只证明了哪一面**"（文件系统已断言，出网/进程 UNCOVERED） |

> **一条绿判据，要么能被真实数据触发，要么标明"前瞻守卫 / 当前无数据"。**

## 7. 关键坑（**我们踩过，别再踩**）

| 坑 | 怎么避 |
|---|---|
| **猜 API 路径** | **读调用方/规范的 `fetch`**，别猜（我们猜过 4 个端点全 404） |
| **静默失败** | **任何失败都要可见**（`/v1/testpage` 曾点处理啥都不显示） |
| **`refused` 读顶层** | `/v1/task` 的字段**嵌在 `plan.*` 里**——**先读结构表** |
| **`&` 后台化整条链** | shell 里 `cmd &` 会后台化 pipe 里全部——**服务没起来就 curl** |
| **锚点打偏** | 改代码时**锚点要唯一**，否则补丁静默不生效（grep 回读） |
| **英文引号截断** | 嵌引号一律用 `「」`；**commit message 用 `-F 文件`**，不用 `-m` |
| **白名单必然漏** | 别维护步骤名/词表白名单，**用类型或"零副作用"断言** |
| **别名两用途混用** | **路由可全别名；改写只许专名**（否则"文件"→`file-store`） |
