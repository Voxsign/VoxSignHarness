# 路由台账、`/api/*` 尾随字节盲区、以及"等价假设"的两类

## 1. 台账落盘（`route/ledger.go`）——让三个考察指标可算

Peter：「大概什么时候用什么模型……**要有记录**。」落盘前台账只在返回值里，**考察点无法考察**。

- **append-only JSONL**：`data/route/ledger.jsonl`（0600，每次 `Write` 后 `Sync`）。
- 每条字段：`at / task / level / model_id / reason / escalated / degraded / outcome /
  kind / kind_fallback / route_ambiguous`（对齐 `VHS-OUTPUT-001`）。
- **可聚合**：`Aggregate(path)` → `Summary`：
  - 考察点① **L0 比例**（低 = 太慢）
  - 考察点② **升级率**（高 = 快模型选错了）
  - 考察点③ **升级后是否真的变好** —— 需要**跨记录对比**（同一任务升级前后），**本层只落盘与聚合，不做因果判断**。
- 空台账/缺失文件返回空摘要**不崩**；坏行跳过不中断聚合。

## 2. ⚠️ 已知盲区：`/api/*` 响应可能含**尾随字节**

**现象**（两处独立实测，同一特征）：
| 位置 | 报错 |
|---|---|
| `route/gateway_route.go` 真调 `/api/route` | `invalid character 'H' after top-level value` |
| Lead 解析 `~/.aiops/service-registry-live.json` | `Extra data: line 1 column 4573` |

**结论**：这不是偶发，是 AIOps 侧的**稳定响应形态**。
**处理**：解析必须"**只取第一个 JSON 值**"（`json.Decoder.Decode` 一次，而非 `Unmarshal` 全部）。
**这不是容错，是对已知形态的适配。**

**代价（盲区，不是已解决）**：若某天响应真的变成"多个 JSON 值"，
我们会**静默只读第一个** —— **看不出**。因此本条登记为**已知盲区**，不是"已解决"。

## 3. "等价是假设，不是事实" —— 两类，第 5 条属第二类

| # | 看起来等价 | 真跑暴露 | 类别 |
|---|---|---|---|
| 1 | 有 `defer Unlock` ⇒ 安全 | `unlock of unlocked mutex` | **我方代码**等价假设 |
| 2 | 滑窗 + 编辑距离单遍 ⇒ 够用 | 吃前缀（`把爱ops接上`→`aiops`） | **我方代码** |
| 3 | 库层判据全绿 ⇒ K9 完成 | HTTP 路径根本没接 `recog` | **我方集成** |
| 4 | httptest 同构 ⇒ main.go 可行 | 真进程未验证 | **我方集成** |
| 5 | **fake 判据全绿 ⇒ 解析正确** | **真端点含尾随字节** | **外部响应形态** |

**第 5 条与前 4 条不同**：前 4 条是**我们自己的代码/集成等价假设**，
第 5 条是**外部响应形态假设** —— **这类最容易漏，因为不由我们控制。**

> **规律：凡是"看起来等价"的地方，都要真跑一次。等价是假设，不是事实。**
> **而"外部响应"这一类，尤其不能靠推理，只能靠真调 + 登记盲区。**
