# 本地测试页：怎么起、怎么用、台账在哪

## 一条命令
```sh
sh scripts/dev.sh
```
它做三件：起服务（默认 `127.0.0.1:8123`）→ 自动打开浏览器 → 数据目录 `data/asr/`。
**不需要懂 Go。** 可选 `AIOPS_KEY`（有则启用模型兜底；没有也能用，纯本地）。
换端口/目录：`VHS_ASR_PORT=9000 VHS_ASR_DATA=/tmp/asr sh scripts/dev.sh`。

## 怎么用
1. 光标放进输入框，**用 macOS 听写说话**（连按两下 Fn）；输入框是标准 `<textarea>`，**没有键盘拦截**。
2. 点 **处理** ⇒ 看到：原始 / 纠错 / 意图 / 是否回问 / 是否降级 / 层级 / 耗时 / 教的词是否命中。
   - **回问时显示候选**（ASK-3b 要求回问必须给候选）；**降级时显示原因**。
3. **教一个词**（term + canonical，如 `哎欧劈艾斯` → `aiops`）· **清空教的词** · **看台账**。

## 台账（这个页面的全部意义）
- **`data/asr/reallog.jsonl`**（append-only，0600）。**每用一次 = 一条真实样本。**
- 每条字段：`at / raw / corrected / intent / ask_back / degraded / level / ms / taught_hit / corrections`。
- **能算出三个考察点**：`L0 比例`、`回问率`（≈升级/回问行为）、`降级率`；
  页面"真实样本"一行直接显示，`GET /v1/testlog?n=20` 亦同。
- **样本 <10 时只报数字、不下结论**（与 `route.Report` 同口径）。
- 与**路由台账**（`data/route/ledger.jsonl`）是两份：一份是"真实使用"，一份是"分层路由"。
  本页记录 **level**（当前本地路径恒为 `L0`，降级时 `L0(fallback)`），两者可按 `at` 对齐。

## 端点（路径一律取自规范，未猜）
| 端点 | 来源 | 用途 |
|---|---|---|
| `GET /` | 本页 | 测试页 HTML |
| `POST /v1/testpage` | 本页 | 纠错+意图+**落真实台账** |
| `GET /v1/testlog` | 本页 | 最近 N 条 + 三个考察点 |
| `POST /v1/observe` | 规范 `VHS-ASR-001` P3 端点清单 | 教一个词 |
| `POST /v1/lexicon {"op":"clear_taught"}` | 同上 | 清空教的词（只清用户教的） |

## 不确定清单（诚实边界）
1. **本页路径恒为 L0**（只用本地规则/缓存，不调模型）⇒ `L0 比例` 在这条路径上会接近 1.0；
   **这不代表整体分层**，只代表"页面这条路径很快"。真正的分层数据要看路由台账。
2. **`/v1/testpage` 未接 `route.Router`**（避免在赶工中引入耦合）⇒ 本页**不产生升级样本**。
3. **"升级后是否变好"仍无法判定**：需要"同一任务升级前后质量"字段（路由台账已留 schema，
   但真实样本仍为 0）。
4. 页面**没有清空 reallog 的按钮**（append-only 是刻意的；要清请手动删文件）。
5. 判据覆盖：页面 200 + 有 `<textarea>`、一次输入 ⇒ 台账多一条、`/v1/testlog` 能算指标
   （tag `vhsui`）。**浏览器交互本身（点击/听写）未自动化**。
