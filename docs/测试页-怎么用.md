# 本地测试页：怎么起、怎么用、台账在哪

## 一条命令
```sh
sh scripts/dev.sh
```
它做三件：起服务（默认 `127.0.0.1:8123`）→ 自动打开浏览器 → 数据目录 `data/asr/`。
**不需要懂 Go。** 可选 `AIOPS_KEY`（有则启用模型兜底；没有也能用，纯本地）。
换端口/目录：`VHS_ASR_PORT=9000 VHS_ASR_DATA=/tmp/asr sh scripts/dev.sh`。

## 怎么用
1. 点 **〔🎤 说话〕**（浏览器原生识别，**零后端、零 key、零依赖**）：边说边出字，说完自动停；
   **文字只填进输入框、不自动提交**（可手动改）；点 **处理** 才提交。
   - 也可光标放进输入框用系统听写（Fn），或**直接粘贴**——录音只是多一条入口。
   - ⚠️ **浏览器支持**：Chrome / Edge / Safari（`webkitSpeechRecognition`）；
     **不支持时按钮置灰并提示"请手动粘贴"**（不白屏、不静默失败）。
   - ⚠️ **隐私**：浏览器原生识别会把**语音送到 Apple/Google 的识别服务**，
     **不是本地识别**。对"测 harness"没问题（我们要的正是**真实带错的 ASR 文本**），但需知情。
2. 点 **处理** ⇒ 看到：原始 / 纠错 / 意图 / 是否回问 / 是否降级 / 层级 / 耗时 / 教的词是否命中。
   - **回问时显示候选**（ASK-3b 要求回问必须给候选）；**降级时显示原因**。
3. **教一个词**（term + canonical，如 `哎欧劈艾斯` → `aiops`）· **清空教的词** · **看台账**。

## 台账（这个页面的全部意义）
- **`data/asr/reallog.jsonl`**（append-only，0600）。**每用一次 = 一条真实样本。**
- 每条字段：`at / raw / corrected / intent / ask_back / degraded / level / ms / taught_hit / corrections`。
- **能算出三个考察点**：`L0 比例`、`回问率`（≈升级/回问行为）、`降级率`；
  页面"真实样本"一行直接显示，`GET /v1/testlog?n=20` 亦同。
- **样本 <10 时只报数字、不下结论**（与 `route.Report` 同口径）。
- 与**路由台账**（`data/route/ledger.jsonl`）是两份：一份是"真实使用"，一份是"分层路由"。
  本页记录 **level**（当前本地路径恒为 `L0`，降级时 `L0(fallback)`），两者可按 `at` 对齐。

## 端点（路径一律取自规范，未猜）
| 端点 | 来源 | 用途 |
|---|---|---|
| `GET /` | 本页 | 测试页 HTML |
| `POST /v1/testpage` | 本页 | 纠错+意图+**落真实台账** |
| `GET /v1/testlog` | 本页 | 最近 N 条 + 三个考察点 |
| `POST /v1/observe` | 规范 `VHS-ASR-001` P3 端点清单 | 教一个词 |
| `POST /v1/lexicon {"op":"clear_taught"}` | 同上 | 清空教的词（只清用户教的） |

## 不确定清单（诚实边界）
1. **本页路径恒为 L0**（只用本地规则/缓存，不调模型）⇒ `L0 比例` 在这条路径上会接近 1.0；
   **这不代表整体分层**，只代表"页面这条路径很快"。真正的分层数据要看路由台账。
2. **`/v1/testpage` 未接 `route.Router`**（避免在赶工中引入耦合）⇒ 本页**不产生升级样本**。
3. **"升级后是否变好"仍无法判定**：需要"同一任务升级前后质量"字段（路由台账已留 schema，
   但真实样本仍为 0）。
4. 页面**没有清空 reallog 的按钮**（append-only 是刻意的；要清请手动删文件）。
5. 判据覆盖：页面 200 + 有 `<textarea>`、一次输入 ⇒ 台账多一条、`/v1/testlog` 能算指标
   （tag `vhsui`）。**浏览器交互本身（点击/听写）未自动化**。

## `/v1/task` 响应结构（**先读结构，别猜字段**）

**顶层**：

| 字段 | 含义 |
|---|---|
| `execute` | **恒为 `false`** —— 本轮只规划，不执行 |
| `goal` | 参与规划的目标文本（**不再写"附文档 N 字"**——那是"看起来读了"） |
| `document_read` | 文档是否真的参与规划（空文档 ⇒ `false`） |
| `document_note` | `document_read=false` 时的**显式原因**（如"document 为空（未参与规划）"） |
| `document` | `{lines, items, todos, keywords, too_large}`（**摘要，不是全文**） |
| `plan` | **嵌套对象**，见下 |
| `note` | 「本轮只规划，不执行；document 仅作规划输入，不落盘。」 |

**`plan.*`（全部在 `plan` 里，不在顶层）**：

| 字段 | 含义 |
|---|---|
| `steps[]` | `{index, tool, caps, action, output, why?, domain?, depends_on?}` |
| `refused` / `reason` | 是否拒绝 / 原因 |
| `missing[]` | **做不到什么 + 该找谁**（owner 前缀：`人：` / `网关：`） |
| `source` / `degraded` / `degraded_reason` | 来源（rule/model/readonly-probe）与降级说明 |
| `considered[]` | 轨迹：这次**考虑了哪些要素**（含 `document:` 结构与 `document_entity:` / `document_hit:`） |
| `wm` | `{w_max, w_used, w_drop, w_drop_trace, chain_len, capacity, demand_floor, familiarity, capped}` |

> ⚠️ **踩过的坑**：顶层读 `refused` 会得到 `None`（它在 `plan.refused`）。**先读本表，别猜。**

## 文档真的被读了吗（真跑证据，2026-10-03）

```
空文档:   document_read=False | note=document 为空（未参与规划） | considered=2 | wm.used=2
有文档:   document_read=True  | considered=9 | wm.used=8
          considered[0] = "document: 4 行 / 4 条目 / 2 个 TODO"
```
⇒ **同一任务下规划结果确实因文档而变**（considered 2→9、`w_used` 2→8），
且**文档只以"结构 + 关键词"参与，不把全文塞进提示词**；`document` 仍**不落盘**。

## 文档读取的边界（诚实）
- **超限**：> 200000 字 ⇒ 截断摘要并**降级**（`degraded=true` + 原因），不静默；
- **空文档** ⇒ `document_read=false` + `document_note`，不静默当"没有"；
- **关键词抽取**是**朴素分词**（汉字连续段 ≥2 字 / 拉丁 ≥3 字），**未做词性/语义**；
- 目前文档只影响 `considered` / `wm`，**尚未改变"步骤如何选"**（`steps` 仍由目标文本决定）。
