# 这个界面设计的核心（交互怎么发生的）

| 要素 | 设计说明 |
|-|-|
| **对话流** | 你说的话=右侧蓝色气泡（带声波动画=语音输入）；Harness 的话=左侧白色气泡。一屏一决策，跟豆包/Grok 同一套对话心智 |
| **响应即执行** | Harness 开口先"收到：复述目标＋边界"（轻标签：意图/域/风险），然后执行卡实时滚动步骤——状态可见是交互根基 |
| **回执即证据** | 完成后一张绿色回执卡：动作/文件/结果/撤销——结果可见、可撤销、可归因 |
| **打断** | 你说"停"→ 红色系统条立即显示：已生效什么、未执行什么、可继续或撤销——控制权在你这 |
| **内部细节压缩** | ASR 转写/纠错/域/风险全部折叠成小标签，不打断对话节奏——你关注的是结果与掌控，不是内部流水线 |

# 为什么照豆包/Grok 做

- 对话式界面是已经被验证最好的 Agent 交互心智：说话即输入、响应即进度、打断即控制
- iOS 壳（VoiceSign APP）按这个界面逐元素实现：气泡/标签/执行卡/回执卡/系统条各对应一条交互 v2 规则
- 后续扩展：多角色折叠（Planner/Executor/Verifier 切换）、need_ask 候选按钮、/cancel——与 M4 server 落地同步
