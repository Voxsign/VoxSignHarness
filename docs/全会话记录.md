## 八、架构与设计共识

### 8.1 总体形态

- **Go 单二进制**：仅标准库、零第三方依赖、静态构建（CGO_ENABLED=0）；常驻、毫秒启动、goroutine 并发、跨平台交叉编译。
- **产品链路**：手机 iOS App（交互/ASR）→ center 中枢 → 各设备上的 harness（执行面）。当前阶段 V0 本地闭环验证。
- **分层**：入口层（stdin / HTTP :8765 / REPL）→ 输入容错层 input（原文保留→清洗→词典纠错→意图 JSON(置信度)→低置信回问）→ 路由层 router → 编排层 agent → 模型接入层 provider → 工具层 tools（可插拔 Registry）→ 记忆层 memory；输出 stdout / HTTP JSON / REPL + 轨迹 JSONL（append-only）。

### 8.2 三域（Harness 大域 = record / discuss / control）

| 域 | 一句话 | 职责 |
|-|-|-|
| **record 记录域** | 「我说的每句话都先存下来，一个字不改。」 | 碎片原汁原味沉淀（ASR 原文留底），只追加不改写；做长期数据素材 |
| **discuss 讨论域（建模域）** | 「把事聊明白，模型就长厚一层。」 | 把不成熟想法建模成认知模式（OGSM/决策/边界）；低置信回问、结论显式化 |
| **control 控制域（执行域）** | 「动手干，干完对账：是我想错了还是没干好。」 | 执行意图、调工具、达成结果；执行前 space_check（默认拒绝），执行后对比归因回写 discuss |

闭环：record（素材）→ discuss（认知）→ control（结果）→ 归因对账 → 回喂 discuss → 新一轮。三域共享词汇表/认知层/轨迹层。

### 8.3 三环（控制系统伪代码层）

- **Record 环（永转）**：语音无条件先记录、轨迹 append-only、配额超了只压缩不改写。
- **Control 环（快环：意图→结果）**：指代消解 → 域选择+边界检查（默认拒绝，越界 BOUNDARY_VIOLATION 永不就地放行）→ 风险分级（可逆×影响面×置信三信号）→ 不可逆永远人工 → 执行（契约白名单）→ 独立 verify（读实际状态 diff 预期，不读自报）→ 四行回执 → 归因回写。
- **Discuss 环（慢环：不确定性→定义）**：定位不确定性类型 → 提问协议（只问边界案例和代价）→ 共识固化只改定义层（词典/域/契约）不改代码 → 任务升级则回 Control 重跑。
- **北极星**：认知闭环周期（record→discuss→control→归因转一圈的速度），而非单任务完成率。
- **异常升级矩阵**：工具失败就地重试上限 1 次→升级 Discuss；越界永不放行；低置信显式回问；崩溃回轨迹恢复点；归因矛盾回 Discuss。

### 8.4 五原则（未来开发规范共识）

### 8.6 VSL（描述定义语言）

- **定位**：代码语言（Go，严格逻辑，机器执行）与描述定义语言（VSL，软约束/规则，大模型理解执行）分离；先定义、后代码。
- **词汇**：space 域 / entity 实体 / contract 契约 / intent 意图（8 类：EDIT/DEBUG/QUERY/TEST/COMMIT/DEPLOY/NOTE/ASK）/ acceptance 验收 / reference 指代 / confirm 确认 / trace 轨迹。
- **定义块**：`.space` / `.dict` / `.contract` / `.policy` / `.accept` / `.ogsm`。
- **v1.1 自然语言优先**：每个定义块一句话人话在前，结构化字段在后。
- **v2 判断语义层（灵魂层）**：每个定义强制回答「如果错了——错在哪（anti）、代价是什么（cost）、机器怎么反问（ask）」；模型=可被推翻的信念+更新规则，控制=可被验证的承诺+中断准则；共识状态机：已确认→暂定（带置信）→待问→已失效。

### 8.7 性能基线（5.7µs 级）

- 口径：`BenchmarkPipelineProcess` = 纯本地分类/容错管线（不含网络/模型/执行），红线 9.9µs（SPEC §1#53）。
- 演进：M2 实测 8.1µs → M3 7.7µs → M4 中位 6.1µs → M5 中位 5.7µs → M6 持平 5.7µs → **M7 复跑中位 5.7µs**。
- 北极星可测阈值：单任务 NetMs < 500ms（仅本地 Go 管线）；LoopMs/NetMs 双报。
