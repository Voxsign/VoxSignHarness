# VoxSign Harness · 下载 / 编译 / 安装 / 测试 接入指南（2026-10-04）

> 给新接手机器/Agent 的明确操作手册。照做即可跑起来并验证。

## 0. 这是什么

VoxSign Harness（VHS）= 长程任务执行引擎：喂一份需求文档 → 自动识别实现意图 → 生成实现计划 → 生成 Go 代码 → **证据门逐端点验收** → 缺口自动修订轮 → 达标后自动 git 提交。**无人工干预**设计（3 洞已焊：端点存在性判据 / 修订表述识别 / LLM 消费验收反馈）。

## 4. 编译

```bash
# 全量编译（零第三方依赖，仅标准库）
go build ./...

# 编译可执行文件（serve 入口 = 根 main.go）
go build -o /tmp/vhs_harness .
```

## 5. 安装 / 运行（起服务）

```bash
# 起 harness 服务（HTTP API 入口，默认 127.0.0.1:8941）
export AIOPS_KEY="<你的网关读 Key>"
VHS_ADDR=127.0.0.1:8941 VHS_LOG_DIR=/tmp/vhs_log /tmp/vhs_harness serve

# 验证
curl -s http://127.0.0.1:8941/v1/health
# → {"bind":"127.0.0.1:8941","ok":true,"tasks":0,"token_set":false}
```

模型配置（已切性价比档，无需改）：
- `config/model-center.json`：default=deepseek-flash、plan=fast(flash)、research=gpt-4o-mini、diagnose=v4-pro
- `config/plan.json`：l2_model=deepseek-flash

## 6. 测试

### 6.1 门禁（全量单测）
```bash
sh scripts/gate.sh          # 期望全绿
sh scripts/board.sh         # 看板
```

### 6.2 无人工长程任务（核心测试）

```bash
# ① 投递任务（text=意图表述，document=需求全文）
curl -s -X POST http://127.0.0.1:8941/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"text":"把这份需求文档实现出来，生成可运行的 Go 后台服务并提交到仓库","request_id":"t-accept-20261004","conversation_id":"accept","document":"<需求全文>"}'
# → {"status":"running","task_id":"task-xxxx"}

# ② 若 need_confirm → 确认执行（设计内授权动作）
curl -s -X POST http://127.0.0.1:8941/v1/tasks/task-xxxx/answer -H 'Content-Type: application/json' -d '{"answer":"执行"}'

# ③ 轮询至 done
curl -s http://127.0.0.1:8941/v1/tasks/task-xxxx
# → status=done 时查看产物：harness-output/<标题>/（git 自动提交）
```

**期望行为**：harness 自动多轮收敛（证据门检出缺端点 → 修订轮 → 补齐）→ 产物端点全部注册才 done；产出目录 + git 提交留痕。

## 7. 常见问题

| 现象 | 原因 / 解法 |
|---|---|
| serve 启动打印 provider 未配置 api_key warn | 正常（openai/gemini 直连通道未配 key；实际走 aiops 网关，AIOPS_KEY 已设即可） |
| 任务 need_confirm 后不继续 | 未 POST /answer；第 2+ 轮自动跳过确认 |
| 任务 blocked（round-limit） | 证据门 20 轮未过 → 查 LastRoundGaps 缺口喂给模型修订 |
| push 被拒（fetch first） | 远端有新提交：`git pull origin main --rebase && git push origin main` |
| 产物 commit 失败 | 本地仓库无 GitHub 凭据 → 配好凭据再跑（或只验收不投长程任务） |

## 8. 交接要点（给接手者）

- **目标**：无人工干预也能一次成功（投需求 → 自动产出达标产物 → 自动提交）
- **验收标准**：需求端点全部注册 + 证据门 PASS + accept 脚本 ALL_PASS + 校验对齐 ≥90% 双证
- **迭代协议**：我测 → 修订方改 → 我复测（20 分钟一轮）
- **模型**：plan=flash（便宜 3-4x）、research=gpt-4o-mini、v4-pro 仅 diagnose；最差模型兜底链已内置
