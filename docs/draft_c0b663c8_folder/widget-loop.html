大域三域：认知-行动闭环record 保证素材（模型的食物）· discuss 保证认知（模型的骨架）· control 保证结果（模型的手脚）· 对账归因是进化回路
RECORD · 记录域
碎片 → 素材
“我说的每句话都先存下来，一个字不改。”
  • 只追加不改写：原文 100% 保留、可检索可回放
  • ASR 原文留底，先记录后整理
  • 判断层：反例=把整理稿当原话；矛盾记录不瞎选、上报问源
DISCUSS · 讨论域（建模域）
想法 → 模型
“把事聊明白，模型就长厚一层。”
  • 建模=对世界认知的模式（OGSM/决策/项目映射），不是调用模型
  • 讨论越多，对事情灵魂/根本目的越清楚
  • 判断层：立场冲突不附和、必反问；结论显式、可质疑、可追溯
CONTROL · 控制域（执行域）
意图 → 结果
“动手干，干完对账：是我想错了还是没干好。”
  • 执行前 space_check（默认拒绝 + 权限交集）
  • 执行后对比归因：模型/预算没想明白 vs 执行没做到 → 回写讨论
  • 判断层：代价超预期→继续还是停；失败时不做，而非做错后道歉
record → discuss → control → 对账归因 → 回喂建模 → 新碎片触发新一轮
闭环逻辑：碎片原汁原味沉淀（record）→ 讨论把想法建成对世界的模型（discuss）→ 依据模型与验收执行现实动作（control）→ 干完对账“是模型/预算没想明白，还是执行没做到”→ 结论回喂建模，新碎片再触发新一轮。认知与行动互相喂养，底座持续长厚。
