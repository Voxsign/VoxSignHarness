## 2. 安装方式（三选一）

### A. 手机连 Mac，Xcode 直接装（最推荐）
1. iPhone 用数据线连 Mac，Xcode → Window → Devices and Simulators
2. 左侧选中你的 iPhone → 点 `+` → 选 `ios/VoiceSign-真机安装包-20261004.ipa`
3. 装完在手机主屏找 VoiceSign 图标

### B. Apple Configurator 2 安装（无 Xcode 时）
1. App Store 装 Apple Configurator 2（或 `brew install --cask apple-configurator`）
2. iPhone 连 Mac，选中设备 → 右键 → Add → 选 .ipa

### C. 开发者模式 + 手动信任（装完必做）
无论 A/B 哪种方式，**首次启动必须**：
1. iPhone 设置 → 通用 → VPN 与设备管理 → 找到 "Apple Development: Bo Feng" → **信任**
2. 如果提示"未受信任的开发者"，先开启：设置 → 隐私与安全性 → 开发者模式 → 打开并重启

## 3. 如果安装报"设备不在 provisioning profile"

profile 只注册了 3 台设备，你的 iPhone 若不在其中：
1. Xcode → 打开 `ios/VoiceSign.xcodeproj` → 选中 VoiceSign target → Signing & Capabilities
2. 勾选 Automatically manage signing，Team 选 "Bo Feng (Personal Team)" 或 "BO FENG (6YL4T9DDTD)"
3. 把 iPhone 插上，Xcode 会自动注册设备并生成新 profile → **直接 Run**（或重新 archive 打包）

## 4. 连接后台服务（重要）

App 默认连 `http://192.168.8.129:8897`（token=m7-token）——**这是 M7 配置的局域网地址**。

真机安装后要真正说话测试，需要：
- Mac 上跑 `vhs serve`（`VHS_ADDR=0.0.0.0:8897 VHS_TOKEN=m7-token ...`），确保 iPhone 与 Mac 同一 Wi-Fi
- 或者改 `ios/VoiceSign/State/SettingsStore.swift` 里的 base URL 指向实际服务

## 5. 本次构建配置备忘

```bash
# 模拟器构建
xcodebuild -project VoiceSign.xcodeproj -scheme VoiceSign \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/vhs-derived build

# 真机签名构建（free provisioning）
xcodebuild -project VoiceSign.xcodeproj -scheme VoiceSign \
  -destination 'generic/platform=iOS' \
  -derivedDataPath /tmp/vhs-device \
  -allowProvisioningUpdates DEVELOPMENT_TEAM=6YL4T9DDTD CODE_SIGN_STYLE=Automatic build

# 打包 ipa
mkdir -p /tmp/vhs-ipa/Payload && cp -R <app> /tmp/vhs-ipa/Payload/
cd /tmp/vhs-ipa && zip -qr VoiceSign.ipa Payload
```
