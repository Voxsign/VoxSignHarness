## 5. 已知限制 / 未完成项（如实）

1. **触发词碰撞**："记下 X 测试"含"测试"时可能被 TEST 意图抢先（M4 冒烟暴露，样本绕行验证通过；修复需 input/taskintent 仲裁调整，建议 M5 定义层修复）。
2. **refer 候选仅歧义分支产出**：词典/上下文无命中时回问仅意图候选，无伪造选项（符合设计）。
3. **interrupted 任务需重新提交**：重启后未完成任务不自动续跑（防无人驱动死等），answer 旧 task_id 返回 409。
4. **真实 git 仅限注册 project 域**：未注册域的 COMMIT 仍默认拒绝；git 操作禁 amend/force/reset（防丢改动），未提交改动会并入提交并明确告知。
5. **need_ask 二轮回问**：意图候选点选后若 refer 歧义仍存，会再次回问（一屏一决策点的自然延伸）。
