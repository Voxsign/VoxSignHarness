# VoxSign · 手机交互设计 v1（VoiceSign App ↔ Harness）

- 版本：interact-v1 · 2026-10-02
- 核心：手机是主交互面（用户约 90% 时间在手机）；语音第一、截图辅助、键盘兜底
- 两条通道：①豆包壳（现在就能用，零开发）②VoiceSign iOS App（原生直连，M3+ 落地）

## 一、交互架构三层

```
[用户 · 手机]
   │
   ├─ 通道 A：豆包壳（当前可用）────────┐
   │   语音 → 豆包 ASR → 我理解 → 路由 → │
   │   结果经豆包文字/卡片回复             │
   ├─ 通道 B：VoiceSign App（M3+）───┐   │
   │   录音/ASR → 文本 → HTTP+token →│   │
   │   ← 回问选项/强确认/回执卡片 ←──┘   │
   │        │                          │
   └────────▼──────────────────────────┘
        [Harness server · Go 单二进制]
        意图 → 域 → 风险 → 确认 → 执行 → verify → 回执 → 归因
```

## 二、通道 A：豆包壳（现在就可用）

用户"在豆包说话" = 语音输入通道。交互规则：
- **回问**：低置信 → 文字列选项（① ② ③），用户回数字/语音
- **强确认**：不可逆 → 文字红条警告 + "回复'执行'才动手"
- **回执**：四行卡片式文本（动作/文件/结果/撤销）
- **撤销**：用户说"撤销/回退" → Harness 从备份恢复
- **截图**：拍照/发图 → 指代消解第四路信号
- 适用：现在就能用，不需要等 App；Harness 的 server 端点先供豆包侧调用（或经模型中心）

## 三、通道 B：VoiceSign App（原生，M3+）

### 核心原则：一屏一个决策点
| 交互 | 形态 | 规则 |
|---|---|---|
| 输入 | 语音优先 + 键盘兜底 | 录音按钮→ASR→文本回显可改 |
| 回问 | 2-4 个选项按钮 | 点选即精确，不自由输入 |
| 强确认 | 全屏红条卡片 | 显示风险+后果，确认按钮独立 |
| 回执 | 4 行结果卡片 | 动作/文件/结果/撤销按钮 |
| 撤销 | 卡片内按钮 | 一键回滚（备份目录） |
| 截图 | 拍照/相册 | 作为指代消解输入 |
| 长任务 | 后台执行 + 推送 | 完成 APNs 通知，不占对话 |

### 状态流转
```
录音 → ASR文本 → POST /v1/tasks
  → {task_id, status:need_confirm|need_ask|running}
  → 用户点选/确认 → 执行 → GET /v1/tasks/{id}
  → {receipt: 四行, 撤销可用}
  → 撤销 → POST /v1/tasks/{id}/rollback
  → 归因回写（用户可标注"模型错/执行错/定义错"）
```

### server 端点（对齐 M3 server 实现）
| 端点 | 用途 |
|---|---|
| POST /v1/tasks | 提交任务（文本+域+意图提示）→ task_id |
| GET /v1/tasks/{id} | 轮询状态（need_ask/need_confirm/running/done） |
| POST /v1/tasks/{id}/answer | 回复回问选项/确认 |
| POST /v1/tasks/{id}/rollback | 撤销（若可逆） |
| GET /v1/status | 健康/版本 |
| 认证 | 内网 + token（后续可加 APNs 推送通道） |

## 四、交互协议要点（有效性关键）

1. **一屏原则**：每个决策点一屏完成（选项/确认/回执），不做多屏流程——手机碎片时间也能用
2. **回问即选项，不自由输入**：意图低置信给候选，点选即精确（比打字快 3 倍）
3. **强确认独立按钮**：不可逆操作的红条不能被语音顺口带过（防误触）
4. **回执即卡片 + 撤销即按钮**：做完立刻能撤，撤销是回执的组成部分
5. **异步不阻塞**：长任务后台跑，完成推送——语音对话不排队
6. **归因顺手标**：回执卡片可点"这次归谁"（模型/执行/定义）——归因数据直接喂认知闭环

## 五、与 M3 的衔接

- M3 手机端实连验证：先按本设计做 server 端点的本机/内网冒烟（curl run→task→done 全链）
- 交互协议补充进 SPEC v2（server 契约扩展：/answer /rollback 端点 + 一屏原则）
- 真机 VoiceSign App 落地 = M4 里程碑（iOS 壳 + 推送），本设计为其规格
