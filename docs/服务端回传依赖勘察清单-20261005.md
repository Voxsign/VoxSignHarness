# 服务端回传依赖勘察清单 — iOS 客户端"消耗/用量"类 UI 解耦（2026-10-05）

> 范围：iOS 客户端 `ios/VoxSign/`。目标：把"消耗/用量"类 UI 显示从服务端回传依赖中摘除，确认哪些显示真正依赖服务端字段、哪些是纯客户端数据。纯显示逻辑解耦，不改 UI 布局/交互，不碰改名代码，不 git 提交，不改服务端/Go/root 文件。

## costTokens 赋值点 grep 复核输出

```
$ grep -rn "costTokens" ios/VoxSign ios/VoxSignTests
ios/VoxSign/Core/Models.swift:140:    var costTokens: Int? = nil          // StoredMessage 持久化字段定义
ios/VoxSign/State/AppModel.swift:51:    var costTokens: Int? = nil       // Bubble 字段定义
ios/VoxSign/State/AppModel.swift:875: costTokens: b.costTokens,          // Bubble → StoredMessage 落盘（本地往返）
ios/VoxSign/State/AppModel.swift:897: b.costTokens = m.costTokens       // StoredMessage → Bubble 回读（本地往返）
ios/VoxSign/Views/MessageViews.swift:173: if let cost = CostText.caption(for: bubble.costTokens)  // 显示（本次改动后）
```

结论：5 处引用 = 2 处字段定义 + 2 处本地持久化往返 + 1 处显示。**无任何一处从服务端响应 JSON / SSE 事件解码给 costTokens 赋值**（TaskView/SSE 事件模型里没有 token 用量字段），服务端从不回传 → costTokens 恒 nil。

## elapsedSec 来源确认

```
$ grep -rn "elapsedSec\|lastSubmitAt" ios/VoxSign
ios/VoxSign/State/AppModel.swift:138: private var lastSubmitAt = Date()
ios/VoxSign/State/AppModel.swift:287: lastSubmitAt = Date()                       // 客户端提交时记录
ios/VoxSign/State/AppModel.swift:774: receipt.elapsedSec = Date().timeIntervalSince(lastSubmitAt)  // 客户端计时
```

结论：elapsedSec 是客户端用 `Date()` 差值算出来的（提交时刻 → 回执渲染时刻），不是服务端回传的处理耗时。

## 结论

**当前客户端不存在依赖服务端回传的消耗/用量显示。**
- costTokens 无服务端数据源、恒 nil、nil 即整行隐藏；
- elapsedSec 为客户端计时；
- 其余"用量感"显示（时间、延迟、诊断、badges、附件）全部来自客户端本地。

本次改动把原来隐式的 `if let tokens = bubble.costTokens { Text("消耗 \(tokens)") }` 容错，改为显式可测纯函数 `CostText.caption(for:)`（nil → nil → 隐藏），并以 4 例单测固化"服务端不回传则隐藏"的容错语义，作为后续开源化协议解耦（客户端不依赖任何私有用量字段）的代码级依据。UI 布局与交互零改动。
