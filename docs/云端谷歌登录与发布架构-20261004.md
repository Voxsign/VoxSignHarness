# VoiceSign 云端谷歌登录与发布架构（HLD）

> 状态：设计定稿待确认 · 2026-10-04
> 关联：产品定位与云架构理念-20261004.md（理念/定价）· ASR接口契约-20261004.md（ASR 通道）

## 1. 目标与边界

- 身份：**谷歌账户为唯一身份**，无注册体系，登录即租户（Google `sub`）。
- 部署：云端默认、本地可选；同一套 harness 二进制支持双模式（`VHS_MODE=cloud|local`）。
- 商业：免费额度起步 + 15 天体验会员 + 三档会员（Free / Prime / Enterprise），计费挂谷歌账户。
- 服务底座：ASR/LLM 一律走自建平台 aiops.peterzou.com（AIOPS_KEY 只在云端 harness 持有，绝不下发 iOS）。
- 本设计范围：谷歌登录链路、租户模型与配额、云端发布形态、测试规划、实施顺序。

## 2. 范式检查（先新范式，后旧经验）

| 问题 | 结论 |
|---|---|
| 新范式下怎么做 | 身份=谷歌账户（零注册摩擦）；云端=统一网关+租户命名空间；本地=可选旁路 |
| 过去为何这么做 | 传统 SaaS 自建账号体系，注册/密码/找回成本高 |
| 约束是否已消失 | 谷歌 OIDC 成熟、免费额度可挂 OAuth 身份、Apple ATS 强制 HTTPS 已有免费证书方案（caddy/Let's Encrypt） |
| ADR | ADR-001：谷歌账户即租户，不建用户表，仅存 `sub → {tier, quota}` |

## 3. 系统上下文与容器（C4 L1/L2）

```
用户(谷歌账户)
  │ iOS VoiceSign（语音交互，纯录音→ASR）
  ▼
VoiceSign 云端网关（harness, mode=cloud）          ← 同一二进制 mode=local 即本地端
  ├─ /v1/auth/google     谷歌登录（OIDC Code+PKCE）
  ├─ /v1/tasks           意图→门禁→执行→回执
  ├─ /v1/asr             ASR 转发（热词网关）
  └─ /v1/me              租户/额度/档位
  │
  ├── 平台 aiops.peterzou.com (/api/model/asr, /api/model/chat) → 阿里 DashScope（千问）
  └── 本地能力（天气 wttr.in、截图、文件系统、远程命令）
```

- iOS 只做三件事：录音→WAV、提交任务、渲染回执；**不持有任何 key**。
- 会话：登录后 harness 发**自签短效 JWT**（HS256，10h，含 `{sub, tier, exp}`），iOS 后续请求带 Bearer。

## 4. 谷歌登录链路（OAuth 2.0 Authorization Code + PKCE）

```
iOS (ASWebAuthenticationSession)
  1. 生成 code_verifier + code_challenge(S256)
  2. 打开 accounts.google.com/o/oauth2/v2/auth?response_type=code&code_challenge=...
  3. 用户谷歌授权 → 重定向回调 → iOS 截获 ?code=
  4. POST 云端 /v1/auth/google {code, code_verifier}
云端 harness
  5. 用 code+verifier 换 Google token（oauth2.googleapis.com/token）
  6. 校验 id_token：本地缓存的 Google JWKS（RS256, kid 匹配），防伪造
  7. 取 sub=租户ID，email=展示名，tier=查配额表
  8. 签发 VoxSign JWT → 返回 {token, tenant, tier, quota}
```

安全要点：PKCE 防拦截；JWKS 本地缓存（5 分钟 TTL）避免每次 RTT；AIOPS_KEY/Google client secret 只存云端环境变量；iOS 无任何机密。

## 5. 租户模型与配额（多租户同机隔离）

| 项 | 设计 |
|---|---|
| 租户 ID | Google `sub`（全局唯一，无需注册） |
| 命名空间 | `<log_dir>/tenants/<sub>/`：hotwords.json、contracts/、backups/、trajectory-<sub>.jsonl |
| 配额计数 | `<log_dir>/tenants/<sub>/quota.json`（asr_seconds/day、tasks/day），原子更新 |
| 免费额度 | 30 条任务/天 + 15 天体验会员（体验期内按 Prime 计） |
| Prime | ¥29/月（年付 ¥198）：不限量、个性化热词、多设备、优先队列 |
| Enterprise | ¥499/月起：团队共享热词库、专属云托管、SLA |
| 超限 | 429 `{code:"quota_exceeded", message:"今日额度已用完，升级 Prime 解锁"}` |

## 6. 云端发布形态

| 形态 | 说明 | 阶段 |
|---|---|---|
| C 本地模拟云端 | 129/索菲亚跑 `VHS_MODE=cloud`，内网 IP 实测登录+租户+配额（iOS 局域网 ATS 豁免） | **P2 先做** |
| A 平台同机子域 | aiops.peterzou.com 同 VPS，Caddy 反代 + Let's Encrypt，云端入口 `https://voicesign.ai` | P3 首选 |
| B 独立 VPS | Docker 单二进制（CGO_ENABLED=0）+ systemd + Caddy TLS | P3 备选 |

- Apple ATS：公网必须 HTTPS（`NSAllowsLocalNetworking` 只豁免局域网）→ 云端 URL 一律 `https://voicesign.ai`。
- 品牌：Google 授权页与重定向域名统一使用 VoiceSign.ai（登录弹窗对用户显示"登录的是 VoiceSign.ai"）。
- 部署单元：Dockerfile（多阶段构建 Go 二进制）+ docker-compose（caddy + harness）+ 日志卷。

## 7. 数据与存储

- 仅三类持久化：`tenants/<sub>/`（热词/契约/回执）、`quota.json`、`server.log`；全部本地文件系统，无外部 DB（沿用 M1 16GB 约束）。
- 迁移：GitHub 为代码唯一权威源；运行数据用 rsync 搬迁（129 → 索菲亚）。

| 判据 | 内容 | 方式 |

## 9. 实施顺序

- **P0（harness 侧）**：`VHS_MODE=cloud` 模式开关 → `/v1/auth/google`（JWKS 验证+JWT 签发）→ 租户命名空间 → 配额计数 → R15/R16/R17 通过
- **P1（iOS 侧）**：Settings 增加"登录 Google / 云端模式"，ASWebAuthenticationSession + PKCE，登录态展示（租户邮箱/档位/剩余额度），云端 URL 可配
- **P2**：129/索菲亚跑云端模式实测全链路（含真实语音 ASR）
- **P3**：voicesign.ai 部署（Caddy TLS）→ App Store 上架（测试版→正式版）→ 计费挂谷歌账户

## 10. ADR 摘要

- ADR-001 谷歌账户即租户，不建用户表
- ADR-002 OAuth=Authorization Code+PKCE；JWKS 本地缓存验证
- ADR-003 同一二进制双模式（cloud/local），本地保留 m7-token 兼容
- ADR-004 租户命名空间隔离 + 配额（Free/Prime/Enterprise）
- ADR-005 公网强制 HTTPS（ATS），voicesign.ai 子域 + Caddy TLS
- ADR-006 会话=自签短效 JWT；所有云端密钥只存 harness 侧环境变量
