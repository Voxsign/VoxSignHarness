## 0. 为什么需要"更高架构标准"的桩

LHT-0001 与本会话已修的 G1–G9 全部落在**输入层**（分类器判得对不对）。
但项目的 12 条设计决策里，有若干条是**架构承诺**，它们无法由"某句话判对了"来证明：

| 决策 | 原文 | 能否用行为测试证明 |
|---|---|---|
| #7 自举充分条件 | 「契约注册机制可被语音调用……此链路通之前 **2.0 不存在**」 | ❌ 需要端到端跨模块 |
| #6 独立校验器 | 「读文件系统实际状态**不读执行器自报**；**回执≠验证**」 | ❌ 需要注入故障 |
| #3 域交集 | 「有效权限=交集，**默认拒绝**」 | ❌ 需要未授权路径 |
| #11 组织者机制 | 「确定性编排引擎接管，回执可预测/可白名单/**可幂等**」 | ❌ 需要重放 |
| #10 异常自愈 | 「不是简单降级/静态建议，而是定位模型判断+自愈动作+**学习回写**」 | ❌ 需要真实失败注入 |

本桩把这些**已承诺的架构性质**变成可执行判据。**红色 = 承诺未兑现**，不是"功能没做"。

## 2. A1 详述（当前唯一红灯，建议作为第一优先级）

**决策 #7 原文**：
> 「自举充分条件不是'有独立校验器'，是'契约注册机制可被语音调用'：
> 说'加一个工具把 md 转 pdf'→REGISTER_TOOL→模型生成契约→风险分级→人确认→注册→下次可用。
> **此链路通之前 2.0 不存在。**」

**实测**：

```
"加一个工具把 md 转 pdf"            → REGISTER_TOOL ✅
"给我加个工具，能把 markdown 转成 pdf" → REGISTER_TOOL ✅
"注册一个命令，用来压缩图片"          → UNKNOWN      ❌
```

**为什么这是架构问题而不是措辞问题**：用户说"注册一个**命令**"，而分类器只认"工具/注册工具"这类词。
但北极星原话是「我要的就这么简单个东西」——**用户不会迁就系统的词表**。
自举入口对措辞敏感，等于自举链条在真实口语下断链。

**验收标准（可机械判定）**：
1. 上述三句全部判 `REGISTER_TOOL`；
2. 不得因新增触发词而把正常 `EDIT`/`QUERY` 误判为 `REGISTER_TOOL`（需回归保护）；
3. 既有 20 条样例仍 20/20。

## 3. A4 详述（判据已登记，夹具待建）

**M8 自报缺口 #3**：「LLM 输出非确定性：重跑同任务可能因措辞微变产生新 commit；**严格幂等仅逐字节相同时触发**」。

**架构判据**：同一长任务重放两次，**不得产生第二个提交**。幂等是决策 #11 的承诺，不是最好努力。

**当前为何是 SKIP**：需要真实 git 仓库 + 模型 provider。
**建议夹具**：临时 git repo + 可复现的确定性 LLM stub（同一输入必返回同一输出），
断言 `git rev-list --count HEAD` 在两次运行后不变。

## 4. A6 详述（判据已登记，依赖真实 JEV）

**M8 自报缺口 #7**：「jev-diagnose 当前为**模拟桩**（模型中心侧），真实 JEV 模型未上线」。

**架构判据**：一次真实失败必须产生 ①带 cause 类的诊断 ②自愈动作 ③**学习回写**；
且同类失败再次发生时，能检索到上次回写（这才叫"回写闭环"）。

**建议夹具**：注入确定性失败（如 `git commit` 到只读仓库）→ 断言诊断记录的 cause 类非空 →
以同一指纹再失败一次 → 断言命中知识库而非重新诊断。

## 5. X1：一条从三次真实事故里长出来的结构性守卫

本会话修 G1–G9 时，**同一类缺口踩了三次**：

| 事故 | 新分支 | 被谁绕过 |
|---|---|---|
| G1-P4 | 否定仲裁（negation） | `llmIntentFallback` 清空 Ask |
| G3-P3 | 元指令仲裁（meta） | 同上 |
| G5-P0-1 | 多动作仲裁（multi_action） | 同上 |

三次都是「**新增一条靠 Ask 拦住的分支，却忘了登记下游会清空 Ask 的路径**」。
所以 X1 不再逐个登记，而是立一条结构性不变式：

> **任何 `Conflict` 非空的意图，其 `Ask` 必须非空。**

这样新增仲裁时自动受保护。**建议实现方同样改写 `llmIntentFallback` 的豁免逻辑——
从"白名单 switch"改为"Conflict 非空即豁免"**，否则还会有第四个实例。
