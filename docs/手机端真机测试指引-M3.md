# VoxSign Harness · 手机端真机测试指引（M3/M4）

- 版本：v1.2（2026-10-02，M4 更新：request_id 幂等、need_ask 续跑、任务持久化、备份路径回执）
- 适用：手机（iPhone/Android）通过内网 HTTP 使用 VoxSign Harness 语音驱动开发底座
- 前提：Mac 上已构建 `vhs` 单二进制（`go build -o vhs .`）
- 交互规范：docs/INTERACT-v1-手机交互设计.md（一屏一个决策点）

---

## 1. 一句话

Mac 起一个 HTTP 服务，手机连同一 Wi-Fi 访问：语音转文字后 POST `/v1/tasks`，轮询 `/v1/tasks/{id}` 拿状态（`need_ask` 回问 / `need_confirm` 强确认 / `running` / `done`）；需确认的任务 POST `/v1/tasks/{id}/answer` 批准或拒绝；可逆操作做完可用 `/v1/tasks/{id}/rollback` 一键撤销。

## 2. Mac 端启动（3 步）

1. 准备独立日志目录（**首次建议先隔离，避免写入默认目录**）：
   ```bash
   mkdir -p ~/vhs-mobile/log && cd ~/vhs-mobile
   ```
2. 起服务（绑内网地址 + 设 token；配了 token 则手机与本机都必须带 token 访问；隔离目录下派生目录 spaces/cache/contracts 会自动跟随）：
   ```bash
   VHS_LOG_DIR=~/vhs-mobile/log VHS_ADDR=0.0.0.0:8765 VHS_TOKEN=换成你的token ./vhs serve
   ```
3. 查 Mac 内网 IP（设置 → Wi-Fi → 详细信息，或终端 `ipconfig getifaddr en0`），记下形如 `192.168.x.x` 的地址。

## 3. 手机端（任一方式）

**方式 A：直接 curl**（iPhone 的快捷指令 / Android Termux 均可跑）

```bash
# ① 发任务（说转成文字后填 text）
curl -X POST http://192.168.x.x:8765/v1/tasks \
  -H "Authorization: Bearer 你的token" \
  -H "Content-Type: application/json" \
  -d '{"text":"记一下明天给客户发报价"}'
# → {"task_id":"task-...","status":"running"}（202）

# ② 轮询状态（running / need_ask / need_confirm / done）
curl http://192.168.x.x:8765/v1/tasks/task-... \
  -H "Authorization: Bearer 你的token"
# → {"status":"need_confirm","question":"人工放行（不可逆）：…"}

# ③ 回答当前决策点（强确认：answer=执行；回问：answer=选项编号）
curl -X POST http://192.168.x.x:8765/v1/tasks/task-.../answer \
  -H "Authorization: Bearer 你的token" \
  -H "Content-Type: application/json" \
  -d '{"answer":"执行"}'
# → 200 已放行；409 = 当前无待回答的决策点

# ④ 撤销（可逆任务做完后悔了）
curl -X POST http://192.168.x.x:8765/v1/tasks/task-.../rollback \
  -H "Authorization: Bearer 你的token"
# → {"ok":true,"restored":"<log_dir>/notes.md"}；不可逆 → 409
```

**方式 B：iPhone 快捷指令思路**：建两个快捷指令——「发指令」（POST /v1/tasks，输入语音转文字）+「查结果」（GET /v1/tasks/{id}，自动朗读回执的"结果"行）。点一下说句话，再点一下听回执。

## 4. 接口速查（全部实测）

| 端点 | 方法 | 请求 | 返回 |
|---|---|---|---|
| /v1/tasks | POST | {text, space?, request_id?} | 202 {task_id, status}；同 request_id 重复提交 → 200 同 task_id deduped:true |
| /v1/tasks/{id} | GET | — | {status, question?, options?, receipt?, attribution?, reversible?, error?} |
| /v1/tasks/{id}/answer | POST | {answer} | 200 已应答；409 无未决决策点 |
| /v1/tasks/{id}/rollback | POST | — | 200 {ok, restored}；409 不可逆/无可撤销 |
| /v1/status | GET | — | 200 {ok, version, uptime, tasks} |

- 旧端点 `/v1/run`、`/v1/task/{id}`、`/v1/confirm`、`/v1/cancel`、`/v1/health` 保留兼容（新客户端请用上面这套）。
- 任务状态：`running` → `need_confirm`（强确认）/ `need_ask`（回问：question + **结构化 options 候选 [{id,label}]**）→ 回答后**续跑** → `done` / `canceled`；`interrupted` = 重启前未完成的任务（恢复后不自动续跑，需重新提交）。
- **need_ask 续跑**：answer 传候选 id（如 edit/query/note/commit 或 rec:/dict: 目标候选）→ 点选即续跑；传自由文本 → 作澄清重跑。一屏一决策点：一次只答当前决策点，无未决决策点 answer → 409。
- **任务持久化**：任务记录落盘 `<log_dir>/tasks/*.json`；重启后历史任务仍可查询，已完成任务仍可 rollback，未完成标 interrupted。
- 认证：`Authorization: Bearer <token>`；配了 token 后**所有来源都要带**（本机也不例外）；不配 token 则仅 127.0.0.1 免 token，非本机绑定启动时会告警。

## 5. 实测记录（M3 隔离环境实连冒烟，INTERACT-v1 端点集）

| 场景 | 结果 |
|---|---|
| /v1/status 无 token / 有 token | 401 / 200 ok=true version=0.2.0 |
| 注册域内 COMMIT（不可逆） | need_confirm（question=人工放行红字）→ answer"执行" → done，回执四行"撤销：不可撤销（不可逆，已人工确认）" |
| done 后再 answer | 409「当前无待回答的决策点」（一屏一决策点生效） |
| NOTE 追加笔记 | done，notes.md 新增一行 |
| NOTE 后 rollback | 200 {ok,restored}，notes.md 还原到追加前内容 |
| COMMIT rollback | 409「不可逆任务（COMMIT/DEPLOY）禁止回滚」 |
| 说"帮我看看那个文件"（refer 歧义） | need_ask，question=「你说的“那个文件”指的是哪个？」，options 结构化候选（意图候选 + 目标候选） |
| 说"随便弄一下"（UNKNOWN） | need_ask，question=「你是想让我做什么？…」 |
| M4：need_ask 点选候选续跑 | options=[{id:edit,label:"改文件…"},…]，answer 候选 id → 续跑（意图定后 refer 歧义仍可二轮回问） |
| M4：同 request_id 重复提交 | 第二次 200 同 task_id，deduped:true，不重复执行 |
| M4：重启后历史任务 | done 可查可 rollback（精确备份路径）；未完成标 interrupted |
| M4：回执撤销行 | 具体备份文件名（如 notes.md.20261002T….bak） |

## 6. 注意（如实说明）

1. **执行根**：普通语音命令改/建的文件落在 `<log_dir>` 内（如 notes.md）；**注册 project 域后 COMMIT/DEPLOY 在项目根真实执行**（git add -A + commit，不改写历史，确认文案含未提交改动数，禁止 amend/force/reset）。
2. **未注册域的写意图默认拒绝**（global 只读，回问或给建议），不会碰你未授权的文件。
3. **不可逆操作永远人工**：COMMIT/DEPLOY/外发等即使批准过一次，下次仍会再问（不会被缓存"学会"——M3 修复项）。
4. **need_ask 可续跑**（M4）：answer 候选 id 或自由文本 → 从挂起点重跑续做；一屏一决策点（一次只答当前决策点）；若仍有歧义（如先定意图、目标仍不明）会再次回问，属正常。
5. **rollback 精确恢复**（M4）：回执"撤销"行含具体备份文件名（`VHS_BACKUP_PATH:` 契约）；重启后历史任务仍可查询/rollback，未完成标 interrupted（需重新提交）。
6. **本机真实目录保护**：`serve` 默认日志目录是 `~/.voicesign/harness`，里面有你的历史 decisions.log/idea-log.md。首次真机测试建议像第 2 步那样用 `VHS_LOG_DIR` 隔离（隔离目录下 spaces/cache/contracts/tasks 会自动跟随，不会写进默认目录）。
7. 手机与 Mac 需同一局域网；公司/酒店 Wi-Fi 可能隔离设备（AP 隔离），连不上就开手机热点给 Mac 连。
8. token 别写进手机便签明文共享，防局域网内被嗅探（HTTP 明文，后续里程碑可加 TLS）。
