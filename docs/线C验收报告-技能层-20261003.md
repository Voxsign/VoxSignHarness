## 修订建议（接线方案，交实现方）

1. **接线点**：pipeline `execActions` 增加技能类分支（intent 命中技能域时走 skill 链，先于 ORCHESTRATE 降级）。
2. **技能域识别**（C-01）：input/taskintent.go 增加技能类动词集（"调用…技能/用…技能/按…技能"）+ 技能域名词（校准/对齐/检索/写作…），产出 Params{skill_domain, confidence}。
3. **清单来源**（C-02）：skill/fetch.go 接 aiops.peterzou.com/api/skill/skills（Bearer $AIOPS_KEY，现 14 技能含 validate-align 1.0.0），按语义匹配选技能。
4. **调用+产出**（C-03）：技能执行 = 读取技能 SKILL.md → 按其流程真装配执行（如校准：D/C/R 三层取证）→ 产出物写 harness-output/ 或 docs/（复用 file write + 定向提交）。
5. **留痕**（C-04）：execActions 技能分支逐段 emit trajectory（发现/选择/调用/产出），服务日志可 grep。
6. **判据再验**：接线后重跑本报告同一任务，4 条逐条取证。
