| 查 | 结果 |

## 4. 实现侧（deepseek）应当怎么做（双向校准协议）

1. **只对同一份判据**：按本报告 L-01 + H-01..04 逐条对照自己实现**自陈 + 证据**（代码位置/端点/复现命令），**不许自造判据、不许自测自己定义的规格**（VHS-VOICE-001 是 harness 语音规格，不是产品验收——已标注为**标准漂移风险**）。
2. **证据必须真跑**：自陈只算意向，测试方独立重跑才算数。
3. **三态收口**：逐条 PASS/REVISE；信息不足判「无法判定」不猜。
4. **回读确认**：实现侧对判据口径有异议 → 摆证据，升级用户裁决。
