## 5. 已知限制 / 未完成项（如实）

1. **真实 server 不推送逐阶段事件**：执行卡步骤按轮询节奏模拟推进；终态/决策点/回执全部来自真实端点（符合"模拟壳"定位；逐阶段事件流留待 App 原生实现或 SSE 里程碑）。
2. **角色条 active 态**：壳用任务状态 role 字段本地点亮；GET /v1/roles 的实时轮询消费可后续一行接入。
3. **碰撞仲裁是触发词级修复**：仍依赖词典语境词（记下/记个/记录…）；极端混淆句（如"测试一下记下的功能"）可能仍归 TEST——属分类器固有边界，20 样例 20/20 + 碰撞 7 例为当前验收面。
4. **web/ 壳未做浏览器矩阵测试**：Safari/Chrome 语音 API 支持度差异由 webkitSpeechRecognition 探测兜底处理。
