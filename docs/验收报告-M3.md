## 3. 手机端实连冒烟（INTERACT-v1 端点集，本机全链实测）

| 场景 | 结果 |
|---|---|
| /v1/status 无 token / 有 token | 401 / 200 ok=true version=0.2.0 |
| 注册域内 COMMIT → need_confirm → answer"执行" | 全链通过：202→need_confirm（红字 question）→200→done，回执四行"撤销：不可撤销（不可逆，已人工确认）" |
| done 后再 answer | 409「当前无待回答的决策点」（一屏一决策点） |
| NOTE 追加 → rollback | 200 {ok,restored}，notes.md 还原到追加前 |
| COMMIT rollback | 409「不可逆任务（COMMIT/DEPLOY）禁止回滚」 |
| refer 歧义"帮我看看那个文件" | need_ask + question + options（project-map 候选） |
| UNKNOWN"随便弄一下" | need_ask + question |

**实连复验（安全修复决定性验证）**：隔离环境注册 fixcheck 域，COMMIT ① 停 need_confirm → 批准 → done；COMMIT ② 仍停 need_confirm（human 缓存排除生效，不会被"学会"）；批准后 git 无未经批准的提交；缓存只写隔离目录（未再污染 ~/.voicesign）。
