# VoxSign ASR 校准链路接口契约（v1 · 2026-10-04）

> 目的：解决 iOS 本地 SFSpeechRecognizer 识别差（实测把"九万年就准"等口语/专名识别错）。
> 链路：**iOS 录音 → Harness `/v1/asr` → 平台 model-center `/api/model/asr`（阿里千问）→ 校准文本回 iOS**。
> 分工：平台侧 `/api/model/asr` 由用户在 aiops 平台实现（接入阿里千问 ASR）；Harness 与 iOS 侧由本仓实现，已按本契约落地。

## 1. 平台侧（用户在 model-center 增加，本契约即验收标准）

```
POST https://aiops.peterzou.com/api/model/asr
Authorization: Bearer <AIOPS_KEY>
Content-Type: application/json

{
  "model": "qwen-audio-asr",          // 阿里千问音频模型；推荐 paraformer-realtime-v2（中文 ASR 专业）或 qwen-audio-asr
  "audio_base64": "<base64 编码的音频>",
  "mime": "audio/wav",                // 当前来自 iOS：WAV（PCM float32，44.1k/48k 单声道）；建议兼容 audio/mp4(aac)
  "sample_rate": 48000,               // 可选：音频采样率（Hz），无则平台探测
  "language": "zh",
  "hotwords": ["VoxSign", "季总", "截个图"]   // 可选：个性化热词（≤100 词，每词 ≤20 字符），接入千问热词提升
}
```

**成功**（HTTP 200）：

```json
{
  "ok": true,
  "text": "你帮我把后台截个图看一下",
  "duration_ms": 1230,
  "model": "paraformer-realtime-v2"
}
```

**失败**（4xx/5xx，body 必须 JSON）：

```json
{ "ok": false, "code": "asr_bad_request|asr_model_error|asr_audio_decode|asr_quota|...", "error": "人类可读原因" }
```

验收判据（平台侧就绪后，harness 验证器自动跑）：
- [ ] 中文口语（含专名/地名）识别准确率显著优于 iOS 本地（抽样 5 句语音原话）
- [ ] 超时 15s 内返回；音频 ≤ 15MB
- [ ] 不可用状态返回明确 `code`（供 harness 透传提示）

## 2. Harness 侧（本仓已实现）

```
POST http://<harness-host>:8897/v1/asr
Authorization: Bearer <harness-token>
Content-Type: multipart/form-data
  file=<WAV 音频二进制>
```

**成功**（HTTP 200）：`{"ok": true, "text": "...", "duration_ms": 1230, "model": "...", "hotwords_used": 8}`
**平台未就绪**（HTTP 502）：`{"ok": false, "code": "asr_channel_not_ready", "error": "平台 model-center 未提供 /api/model/asr"}`（AIOPS_KEY 缺失时同 code，error 注明）
**音频无效**（HTTP 400）：`{"ok": false, "code": "bad_audio", ...}`

harness 行为：接收 multipart → base64 → 调平台 `/api/model/asr`（AIOPS_KEY，来自 `AIOPS_KEY` 环境变量，与 model-center 通道同一密钥，绝不内置）→ 平台 200 原样透传 `text`；平台非 200 转 502 + 平台返回的 `code/error` 透传。

## 3. iOS 侧（本仓已实现）

- **按住说话**：AVAudioEngine 采集，同时：① 喂本地 SFSpeechRecognizer（仅作失败兜底，**按住期间不显示文字**）；② 写 WAV 临时文件。
- **松手**：UI 进入 **"正在校准…"** 态（不出文字）→ POST `/v1/asr`（multipart WAV）。
- **校准成功**：一次性显示校准文本 → 自动提交（豆包式）。
- **校准失败**（通道未就绪/网络错）：显示「识别失败，请再按一次」→ **不回退本地识别**（v2 起本地识别全部移除）。

## 3.5 个性化热词（v2 结构重设计，2026-10-04 用户定）

**决策**：iOS 不再做任何本地识别（离线兜底全部移除）；ASR 个性化问题**全部在 ASR 服务器（Harness）这一层解决**，iOS 只负责录音与展示。

- Harness 维护个性化热词库 `<log_dir>/personal/hotwords.json`（种子词见下；运行时由用户纠正自动积累）。
- Harness 调平台 `/api/model/asr` 时携带 `hotwords`（上限 100 词/每词 ≤20 字符，paraformer 热词约束）。
- 平台侧（用户实现）须把 `hotwords` 接入千问 ASR 的热词提升通道（paraformer-realtime-v2 支持热词）。
- iOS 校准失败 → 明确提示「识别失败，请再按一次」，**不回退本地识别**。

**热词来源（种子）**：`VoxSign`、`VoiceSign`、`Harness`、`aiops`、`PeterZou`、`季总`、`截个图`、`远程控制`、`查看天气`、`校准`。
运行时积累：用户在对话中纠正/强调的词（"我说的是 XX"）→ harness 提取写入 hotwords.json（去重、限额）。

## 4. 日志与可观测

- harness：`/v1/asr` 记 `asr_channel=platform|local, model=<响应模型>, duration_ms=<平台耗时>, text_len=<校准文本长度>`。
- 验证器：`vhs-validate.py` 新增 R14（/v1/asr 契约可达性：平台就绪 → 文本断言；未就绪 → 断言返回 502 + asr_channel_not_ready 且不 panic）。
