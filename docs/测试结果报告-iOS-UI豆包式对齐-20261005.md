## 6. 遗留项清单

1. **UI 测试 target 配置**：`VoiceSignUITests` 缺 TEST_TARGET_NAME，全 scheme `xcodebuild test` 仍会 exit 65；需命令行 `TEST_TARGET_NAME=VoiceSign` 覆盖才能跑（本轮未改 pbxproj，按约束仅命令行覆盖）。
2. **旧 VoiceSignUITests.swift 3 例失败**：断言关键词（need_ask"哪个"/"撤销|已追加|OK"）与新回执文案、本地 harness 行为失配，需编排者决定是修旧断言还是归档。
3. **NotificationService 通知标题仍含 "VoiceSign · …"**（`Core/NotificationService.swift` 第 55/58/60/63/65 行，共 5 处）——既有遗留文案，按要求不改、仅记录。
4. **按住说话红条/上滑取消**：模拟器无音频，UI 未实测到；需真机（iPhonePeter）按住复核"松开 发送"红条与 -80pt 上滑取消手感。
5. **会话标题抽取**：纯英文首条消息的会话标题仍显示"新会话"（12），中文/正式指令路径未在本轮覆盖。
6. **"消耗 n"信息行**：依赖服务端任务视图回传 token 用量；当前 harness 不回传，该行自动省略（代码正确，端上展示需服务端补字段）。
7. **服务端 attachments 处理**：Go 侧目前不解析 attachments 字段（按 v2.4 设计"服务端忽略未知字段"），端上发送链路已通，服务端消费逻辑待后续。
8. **版本号**：最终打包为 2.6(build 9)；仓库 HEAD 本已 2.5(8)，任务书"2.4/build 7"基于过期提交信息；ipa 文件名按任务书保留 "2.4"，发布命名需对齐。
9. 顶栏橙点（决策态）未截到：本地 harness 本轮未产生 decision 场景。
