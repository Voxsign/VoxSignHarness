## 3. 红线判据（PDF 第 8 章，绝不违反）

| # | 红线 | 测法 |

| R-04 | 不无界膨胀：缓存/知识库有容量上限与过期策略 | 代码回读（容量/过期字段）+ 数据目录增长测试 |

## 4. 非功能判据（PDF 第 7 章）

| 维度 | 判据 | 测法 |
|---|---|---|
| 性能 | 本地规则路径 <1ms；模型兜底超时 3s、并发受限、超时降级 | 压测本地路径耗时统计；模型兜底路径注入超时验证 fail-open |
| 可靠性 | fail-open；数据 append-only；重启快速恢复 | 词典文件损坏 → 服务仍响应；重启后数据仍在 |
| 可观测 | 轨迹 JSONL 全链留痕（耗时/来源/置信度） | L-01.4 复用 |
| 隐私 | 个性化数据本地存储不上传 | 代码回读（无出网路径除模型兜底）+ 数据目录本地 |
| 安全 | 接口鉴权本地回环优先；不执行业务动作 | 非回环请求被拒；执行字段恒 false |
| 兼容 | 意图 JSON 契约与 Harness 8+1 兼容 | 与线 A `/v1/tasks` 联调：线 B 输出意图 → 线 A 消费 |
