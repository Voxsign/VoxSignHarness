# 模拟覆盖的交互全链（iOS 壳开发对齐基准）

| 环节 | 模拟内容 |
|-|-|
| **ASR 识别** | 语音→转写→纠错（季总→冀总）、时间锚点（下周一）、实体（冀总→厂房项目） |
| **意图/域/风险** | 意图标签（NOTE/COMMIT）、域徽章（vault-notes/project）、风险分级（auto 静默 vs 不可逆刹车） |
| **刹车点** | 不可逆操作：强确认红条（是/否/改），防误触、独立按钮 |
| **执行+verify** | 进度滚动、verify 读实际状态不读自报（用户不可见但系统强制） |
| **回执+撤销** | 四行回执（动作/文件/结果/撤销）；可逆给撤销、不可逆明示"已人工确认" |
| **归因** | 归谁（模型/执行/定义）→ 点选回写认知闭环 |
| **打断** | 说"停"立即截断（barge-in），停播/停止/撤销分离 |

# 这个模拟器的用途

- **改 iOS 代码的基准**：每个界面元素（语音气泡/标签/刹车卡/回执卡/归因按钮）对应一条交互设计规则，实现时逐条对齐
- **验收口径**：首次有效反馈延迟 / 纠正次数 / 误操作率 / 停止生效时间
- 后续可扩展：need_ask 候选按钮、/cancel、进度事件（SSE）——与 M4 server 落地同步更新
