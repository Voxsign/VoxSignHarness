## 1. 主体 / 参照的最终定位（第三次澄清后才定的）

| 角色 | 是什么 | 干什么 | 不干什么 |
|---|---|---|---|
| **voice-sign harness** | **主体** | 做所有事：识别、门禁、执行、校验、回执、测试 | —— |
| **vhs-asr**（`asr/` 层） | harness 的**内层能力** | 个性化识别；可单独部署，但**代码属于 harness** | 不碰域门禁/执行/回执 |
| **DeepSeek** | **参照 + 裁判** | ① 同语料做对照 ② 异源盲评判分 | **不产出**（不写实现、不参与设计决策） |

**说明**：我曾两次把主体搞错——先当 DeepSeek 是对照臂，后当 DeepSeek 是建设者。
用户两次纠正。**主体始终是 voice-sign harness。**

## 2. 代码组织（"这个怎么处理"的答案）

**一个仓库、一个 Go module、两个产物。**

```
voicesign-harness/                  一个 module（go.mod 只有 module + go）
├── input/ memory/ pipeline/ …      现有 harness（本轮不动）
├── asr/                            【新】ASR 个性化识别层
│   ├── engine.go                   快路引擎
│   ├── types.go                    接口类型（CorrectRequest/Result/Correction/Feedback）
│   ├── corpus/real-dialogue.jsonl  真实语料（15 条起，随对话增长）
│   └── harness_test.go             它自己的桩（先红）
└── cmd/
    ├── vhs/                        现有主程序（harness 服务）
    └── vhs-asr/                    【新】独立服务入口 —— 单独部署时才编
```

### 为什么这样分

| 关注点 | 处理 | 理由 |
|---|---|---|
| **代码在哪** | **同仓库同 module** | 共用语料、判据、桩；**版本永远一致**——直接消灭"这个版本那个版本"问题 |
| **依赖方向** | 单向：`harness → asr`，**绝不反向** | asr 不知道 harness 存在，才可能被单独部署、被别的东西复用 |
| **跑在哪** | **运行时选择**：本机 / 另一台服务器 / 两边 | `scp vhs-asr` 即可；同一份代码、同一份测试 |
| **编哪个** | `go build ./cmd/vhs` 或 `./cmd/vhs-asr` | 两个产物来自同一 module，不重复代码 |

**关键判断**：把"部署位置"和"代码组织"**解耦**。
同仓库不阻碍异地部署；异地部署也不要求拆仓库。

## 3. 对架构第一原则的正确应用（v1 用错了）

第一原则说「能力外置，本机极简」。v1 由此推出"asr 必须在另一台机器"——**这是错的**：

- 原则约束的是**能力从哪来**（外部接口 + key，而不是本机装一堆东西），
- **不约束进程跑在哪台机器**。

正确表述：

| 层 | 遵循原则的方式 |
|---|---|
| ASR 个性化识别 | 作为**独立层/服务**存在，harness 通过**接口**调用它（不是把逻辑塞进 harness 主链） |
| 个性化状态 | 由 asr 层自己管，harness 不持有 |
| 模型判断 | 外置：接口 + key |
| **部署位置** | **自由**：本机进程内、本机独立进程、异地服务器，三种都合法，同一份代码 |

## 4. 测试桩（两个用途，用户明确"两个都需要"）

1. **自己和自己比**：同一批真实语料，跑**改动前 / 改动后**两条，出数字
2. **异源盲评**：DeepSeek 只看「规格 + 产物」给 PASS/修订/驳回

### 语料
`asr/corpus/real-dialogue.jsonl`（暂存 `eval/asr-corpus/`）——15 条，
**全部来自 Peter 与 DSH 的真实对话**，每条带 `source` 出处。
**每轮对话往里加**——这是"越用越准"能被度量的基础。

### 判据 C1–C4（各带双向反例）
- **C1** 不该纠的不能纠（否定、M7 真机长句必须原样）
- **C2** 触发词同音容错（提交→出交）
- **C3** 噪声不脑补（纯噪声必回问）
- **C4** 可观测（每次纠错带区间/原因/置信度，raw 留底）

### 性能判据
p99 < 1 ms（快路）· 单核 ≥ 10k QPS · 常驻 < 50 MB · **断网可跑**

## 5. 分阶段

| 阶段 | 产物 | 在哪 |
|---|---|---|
| **P0 方向** | 本文档 v2 | 本机（只写文档） |
| **P1 桩** | `asr/` 接口类型 + 语料 + C1–C4 桩，**先红** | 本机（只写测试） |
| **P2 快路** | 归一化 + 词表/热词 + 拼音索引 + AC 匹配 | **不限**（代码同仓库） |
| **P3 服务** | `cmd/vhs-asr` + `/v1/*` + 静态单二进制 | 编出来，跑哪都行 |
| **P4 个性化** | 频次/邻接上下文/衰减 + 在线学习 | 同上 |
| **P5 接上** | harness 调 asr（进程内直调 or HTTP，二选一由配置定） | 同上 |

**P1 先于 P2** —— 判据先于实现。

- 性能数字是**目标不是实测**。

- 我**没有**任何远程服务器的访问权限；"异地部署"目前只是设计上可行，**未验证过**。
