# 一、业界模式参考（2025-2026）

| 产品 | 可借鉴模式 |
|-|-|
| Grok / 豆包 | 边听边答、可打断、自然续接；语音回答同步显示可扫读文本与操作控件 |
| ChatGPT（Mac 客户端） | 统一入口、上下文可见；低成本召回助手（快捷唤起）；避免关键操作藏进模态切换 |
| Claude Code | 计划与执行分层；工具调用与权限请求显式呈现；先看计划再审批高风险动作 |
| Cursor | 结果落在可审阅对象上（变更集/差异审阅/接受拒绝），而非只给自然语言总结 |
| OpenAI AgentKit | 多步任务显示为阶段与事件；流程可检查；Agent 交接不变成黑箱 |

**总判断：**保留对话为入口，但执行过程用任务卡；计划、工具调用、差异、审批都应是可展开的结构化对象，不能只依赖聊天气泡。

# 二、v2 六条逐条评审与增补

## 规则 1｜一屏一决策，但允许安全预览

- **触发：**需补充信息/授权/选择方案
- **行为：**每次只突出一个必做决策；并列展示方案差异、预计影响与默认推荐；可跳过的偏好设非阻塞项
- **视觉：**主按钮写动作（"允许修改 3 个文件"），不用"确定"
- **异常：**问题含糊先给可编辑理解摘要；低风险信息不足用保守默认并标记假设
- **修正：**同任务同风险域可合并审批（逐项列范围），不可合并不同后果的动作——避免决策疲劳弹窗

## 规则 2｜打断/暂停/撤销三语义分离

- **触发：**说"停/等一下/撤销"或点对应控件
- **行为：**停=立即取消；暂停=保留进度等继续；撤销=补偿已完成可逆动作。三者独立 API 状态与回执
- **视觉：**任务卡显示"停止中→已停止"，标注最后一个完成步骤
- **异常：**取消令牌超时/工具不可中断→停后续步骤、提示"当前步骤仍在收尾"，禁止假报已停止；补部分成功语义

## 规则 3｜角色折叠以任务为主线

- **触发：**Planner/Executor/Verifier 参与同一任务
- **行为：**默认自动折叠已完成角色，只留当前角色与待决策项；交接不新建任务、不丢滚动位置/草稿/审批状态
- **视觉：**任务卡固定显示当前角色/阶段/任务名；时间线可展开计划、执行、验证、工具事件；顶部切换器只切视图不改归属
- **异常：**角色失败停在失败角色、展开错误与可恢复操作；禁止悄悄切换角色继续

## 规则 4｜状态可见，回执可验证

- **触发：**执行开始/工具调用/文件变更/验证完成
- **行为：**步骤按发生顺序追加；回执四行固定动作/文件/结果/撤销，链接差异、日志、验证证据
- **视觉：**区分进行中/完成/失败/跳过；长日志默认折叠，当前步骤置顶
- **异常：**证据缺失写"未验证"，不得把模型陈述显示为已验证事实；增加耗时、重试、证据来源

## 规则 5｜风险分级，确认不等于放行

- **触发：**动作触及文件/命令/网络/权限/外部系统
- **行为：**默认拒绝未授权范围；按影响显示具体资源、范围与后果；不可逆始终人工执行或逐步确认；BOUNDARY_VIOLATION 无"继续"按钮
- **视觉：**以动作描述授权，不以抽象权限名授权；高风险与普通继续分区
- **异常：**无法判定风险按更高等级处理；授权范围变化即重新询问；补授权范围、时效、撤回方式；确认只对展示过的具体动作有效

## 规则 6｜"爽感"变可测量门槛

- **触发：**任务完成或用户中止
- **行为：**记录首次有效反馈、纠正次数、误操作、停止生效时间；区分语音/文本入口；内部面板按任务类型/风险查看分布
- **视觉：**运行界面不展示指标
- **异常：**区分网络/工具延迟与 Agent 延迟；样本不足标"不确定"，不以平均值掩盖长尾；定义"有效反馈"=确认理解并给出下一步/可用结果；另跟踪误听率、重复播报率、授权后越界率

# 三、多角色折叠专项

## 规则 7｜按任务状态决定角色展开

- **触发：**角色启动/交接/等待输入/失败
- **行为：**当前角色默认展开，已完成角色自动折叠；需用户决策、角色失败、边界阻断、验证不通过→强制展开；执行中不自动抢回焦点
- **视觉：**顶部"执行中 · Executor"+进度；交接以时间线事件呈现；Planner 显示计划、Executor 显示步骤/工具、Verifier 显示检查项与证据
- **异常：**角色无响应显示超时与重试/停止；Verifier 未完成不得显示任务成功

## 规则 8｜切角色不丢状态

- **触发：**用户点选角色或展开历史记录
- **行为：**保存各角色滚动位置/筛选/草稿/展开状态；切换只改查看内容，不取消任务、不重新授权
- **视觉：**当前执行角色持续标识；查看历史角色另标"正在查看"
- **异常：**历史与当前不同步显示最后更新时间和"刷新"；过期审批不可直接复用

# 四、语音专属增补

## 规则 9｜ASR 不确定先纠错，不擅自执行

- **触发：**人名/路径/命令等关键实体置信度低，或不同识别结果会改变动作
- **行为：**短候选用点选；长句给可编辑转写；简单口误提示"重说这一段"；执行前复述关键实体与动作
- **视觉：**只高亮不确定词，候选按钮不复述整句
- **异常：**连续两次不确定转文字编辑/键盘；危险动作不以"我听起来像……"作确认

## 规则 10｜一份任务状态，语音文字双通道同步

- **触发：**语音与文字之间切换，或任一通道发停止/暂停/撤销
- **行为：**所有输入与控制作用于同一任务；一方停止后另一方立即显示状态；语音被打断停止播报；是否继续后台执行须明确提示并遵守任务授权
- **视觉：**显示听写内容、当前任务状态、最后操作结果；麦克风状态与执行状态分开
- **异常：**通道断连保留任务并提示"仍在执行/已停止"，重连恢复同一任务，不重复提交指令

## 规则 11｜屏幕容量匹配语音节奏

- **触发：**语音播报长内容/连续步骤/等待用户回答
- **行为：**每轮语音只讲结论与当前所需决策；细节按任务卡分段，支持暂停后从断点继续；屏幕内容可多于播报但标注当前播报段
- **视觉：**当前句/步骤跟随高亮；选项与语音顺序一致；关键按钮始终可见
- **异常：**用户插话即暂停播报并优先处理新输入；识别失败不从头重播长段，提供重听/看文字/重说
