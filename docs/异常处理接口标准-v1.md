# VoxSign × 模型中心：异常处理接口标准 v1

> 状态：定稿（Peter 2026-10-02 确认方向：模型中心已实现自愈方式，harness 侧按本标准对接）
> 用途：harness 工具执行/模型调用失败、超时/慢响应时，调"问题定位模型"（JEV）诊断并自愈。

## 1. 端点（模型中心侧实现）

**主方案（推荐）**：复用 OpenAI 兼容通道，零新传输。
```
POST https://model.peterzou.com/v1/chat/completions
Authorization: Bearer <sk-mc-...>
```
模型名（模型中心侧需注册）：`jev-diagnose`

**备选**：若模型中心提供专用端点（如 `/v1/diagnose`），harness 配置 `diag.endpoint` 覆盖即可（优先走专用端点）。

## 2. 请求

```json
{
  "model": "jev-diagnose",
  "max_completion_tokens": 500,
  "temperature": 0.2,
  "response_format": {"type": "json_object"},
  "messages": [
    {"role": "system", "content": "你是 VoxSign 异常诊断模型。根据用户任务与执行失败轨迹，输出结构化 JSON 诊断。只输出 JSON，不要多余文字。"},
    {"role": "user", "content": "{\"task\":\"<用户任务原文>\",\"intent\":\"<QUERY|EDIT|NOTE|COMMIT>\",\"failure\":[{\"tool\":\"<工具名>\",\"args\":\"<参数摘要>\",\"err\":\"<错误信息>\",\"stdout\":\"<输出片段>\",\"model\":\"<被调模型名，无则空>\"}]}"}
  ]
}
```

注：模型不支持 `max_completion_tokens`/`temperature` 时按 harness 现有适配（use_max_completion_tokens 开关、跳 temperature）。

## 3. 响应（choices[0].message.content，JSON）

```json
{
  "category": "budget|network|auth|param|tool_missing|permission|transient|unknown",
  "root_cause": "一句话根因（中文）",
  "confidence": 0.0,
  "recoverable": true,
  "suggestion": "具体可执行建议（中文）",
  "action": "retry|modify|fallback|ask|stop",
  "retry_params": {}
}
```

### category/action 语义

| category | 典型场景 | action 建议 | harness 处理 |
|---|---|---|---|
| budget | 预算/额度用尽 | fallback/stop | 友好降级文案（区分"预算用尽"，不误导为网络） |
| network | 网络不可达/超时 | retry | 指数退避重试（限 2 轮） |
| param | 参数不被支持（如 max_tokens 400） | modify | 按 retry_params 修正参数后重试 |
| auth | key 无效/权限 | stop | 归因提示检查 key，不进自动重试 |
| tool_missing | 工具/能力缺失（如无网络工具） | ask/fallback | 回问用户或安全降级 |
| permission | 执行被拒/无权限 | stop/ask | 归因并转回问 |
| transient | 瞬时抖动 | retry | 重试 |
| unknown | 无法判断 | fallback | 保持现有降级 |

### 判定规则
- `action=retry` 且 `recoverable=false` 冲突 → 以 recoverable=false 为准（stop）。
- `retry_params` 可选；retry 时携带修正参数（如换模型名、新 max_tokens 值、退避秒数）。

## 4. harness 侧调用约定

- **插入点**：① 工具执行 receipt.OK=false；② verify fail；③ queryLLMAnswer 模型调用 err/空内容；④ **超时/慢响应**（ctx 超时 + 可配置快速响应阈值，诊断请求带 model 字段区分不同模型）。
- **三环**：异常知识库命中（exceptions.jsonl，0 模型调用）→ 未命中调 JEV → 自愈执行器（限 2 轮）→ 修复成功回写知识库。
- **失败不扩散**：诊断接口非 2xx / 超时 30s / JSON 解析失败 → 跳过诊断层，走原降级路径，现有行为不变。
- **未配置即跳过**：diag provider 缺失 → 诊断层不启用，链路照常。
