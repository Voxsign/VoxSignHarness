# VoxSign × 模型中心：异常诊断接口 jev-diagnose 契约定稿 v2

> 状态：**定稿**（2026-10-02，模型中心侧已实现模拟桩先行；`jev-diagnose` 已注册）
> 契约与兜底体系关系：**jev-diagnose＝诊断模型**（回答"出了什么问题、下一步怎么办"）；**/v1/fallback＝兜底链路**（保证任何异常最终 100% 有响应）。诊断失败 fail-open 跳过，主链路兜底继续——两者互补。

## 1. 端点与认证

|项|值|
|---|---|
|端点|`POST https://model.peterzou.com/v1/chat/completions`（OpenAI 兼容）|
|模型名|`model=jev-diagnose`（已注册）|
|认证|`Authorization: Bearer <Key>`（与模型中心一致）|
|响应格式|请求带 `response_format={"type":"json_object"}`|

## 2. 请求 schema

```json
{
  "model": "jev-diagnose",
  "response_format": {"type": "json_object"},
  "messages": [
    {"role": "system", "content": "诊断任务失败轨迹"},
    {"role": "user", "content": "任务原文+意图+失败轨迹（结构化数组）"}
  ]
}
```

**失败轨迹（user content，结构化数组）**：

```json
{
  "task": "分析沙特医疗器械市场趋势",
  "intent": "deep_analysis",
  "traces": [
    {"tool": "chat", "params": {"model": "gemini-3.8-flash", "max_tokens": 4096},
     "error": {"code": 503, "type": "overload"}, "model": "gemini-3.8-flash"},
    {"tool": "chat", "params": {"model": "gpt-4o-mini"},
     "error": {"code": 429, "type": "rate_limit"}, "model": "gpt-4o-mini"}
  ]
}
```

> harness 构造时：`traces[].error.code` 尽量带真实 HTTP code；`model` 字段用于区分不同模型。

## 3. 响应 schema（定稿字段）

```json
{
  "category": "transient",
  "root_cause": "上游过载/限流（503/429），非调用方问题",
  "confidence": 0.9,
  "recoverable": true,
  "suggestion": "按退避 5s 重试，最多 2 轮；或改用 model=auto",
  "action": "retry",
  "retry_params": {"backoff_seconds": 5, "max_retries": 2, "cooldown_seconds": 30}
}
```

|字段|类型|说明|
|---|---|---|
|`category`|string|分类（8 类，见 §4）|
|`root_cause`|string|根因（人类可读一句）|
|`confidence`|float|置信度 0-1|
|`recoverable`|bool|是否可恢复|
|`suggestion`|string|建议（人类可读）|
|`action`|string|动作（见 §5）|
|`retry_params`|object|重试参数（backoff_seconds/max_retries/cooldown_seconds）|

## 4. 分类 8 类 + 内部映射

|category|含义|内部 error_type 映射|
|---|---|---|
|`budget`|预算/额度用尽|quota（cost_guard blocked、balance down、subscription 受限）|
|`network`|网络/连接失败|timeout / connection|
|`param`|参数错误|invalid_request（400/422 参数类）|
|`auth`|认证/授权失败|auth（401/403 key 无效/权限不足）|
|`tool_missing`|工具/模型不存在|not_found（404）|
|`permission`|权限不足|permission（白名单外/越权）|
|`transient`|瞬时故障（可重试）|5xx（503 过载）/ 429（限流）|
|`unknown`|无法判定|其他/无匹配|

## 5. 动作语义

|action|语义|条件|
|---|---|---|
|`retry`|按 retry_params 重试|recoverable=true 且 **attempt<2**（限 2 轮）；含退避/冷却|
|`modify`|修改参数后重试|param 类（修正后重发）|
|`fallback`|降级（换模型/渠道/auto）|tool_missing/transient 部分场景|
|`ask`|询问用户/补充信息|unknown 类|
|`stop`|停止（不重试）|**recoverable=false 一律 stop**（budget/auth/permission 等）|

## 6. 容错（fail-open）

- jev-diagnose 调用失败/超时/未配置 → **自动跳过，现有链路行为完全不变**（不阻塞正常 chat/completions）
- 与兜底链互补：诊断→跳过→主链路兜底（/v1/fallback 逻辑）继续保证 100% 有响应

## 7. Mock 场景（X-Mock-Scenario 切换，当前模拟桩）

- 兜底场景：`normal` / `single_channel_down` / `all_channels_down` / `cache_hit`
- 分类场景：`budget` / `auth` / `transient` / `param` / `network` / `tool_missing` / `permission` / `unknown`
- 可控延迟：`X-Mock-Delay-ms`（0-5000）

> 真实诊断（规则→JEV→Opus）迭代上线后同一契约，Harness 对接代码无需改动。

## 8. curl 示例（已实测通过 2026-10-02）

```bash
KEY="sk-mc-xxxx"
curl -s https://model.peterzou.com/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -H "X-Mock-Scenario: transient" \
  -d '{"model":"jev-diagnose","response_format":{"type":"json_object"},
       "messages":[{"role":"user","content":"{\"task\":\"分析沙特医疗器械市场趋势\",\"traces\":[{\"tool\":\"chat\",\"error\":{\"code\":503}}]}"}]}'
```

**实测记录**（harness 侧 2026-10-02）：
| scenario | category | action | recoverable | suggestion |
|---|---|---|---|---|
| transient | transient | retry | true | 稍后重试 |
| budget | budget | stop | false | 充值或等待配额重置 |
| auth | auth | stop | false | 检查 API key |
| param | param | modify | true | 修正参数 |
| unknown | unknown | ask | true | 人工介入 |

## 9. harness 侧实现要求（与 v1 一致的硬约束）

1. 插入点：工具执行 receipt.OK=false；verify fail；模型调用 err/空内容；**超时/慢响应**（诊断带 model 字段）；
2. 三环：exceptions.jsonl 知识库命中（0 模型调用）→ 未命中调 jev-diagnose → 自愈执行器（限 2 轮）→ 修复成功回写；
3. 失败不扩散：诊断非 2xx / 超时 / JSON 解析失败 → 跳过诊断层，走原降级；
4. 未配置 diag provider → 诊断层不启用，链路照常；
5. 自愈动作仅 retry/modify/fallback/ask/stop；recoverable=false 一律 stop；不自动执行不可逆动作；
6. go test 全绿 + 单测覆盖：未配置跳过/诊断失败跳过/知识库命中/JSON 解析/action 路由/超时纳入。
