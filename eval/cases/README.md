## 1. 这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 人工（Peter）增删改的**真值库** | 由 agent 自动生成、自动扩充的语料 |
| 表达"应该发生/绝对不许发生"的**外部预期** | 从当前实现反推出来的行为快照 |
| 三态判定（`met` / `unverified` / `not_met`）的载体 | 可被折算成百分比或 0 分的打分表 |
| 与 `commit_sha` 绑定的**可复算**观测 | 一次性的、脱离版本的结论 |

原话依据：`eval/cases.jsonl` 由**人**增删改（30 条基准 + 每 feature 增补），**harness 只跑不改**——这是「外部真理源」（`...自举方案.html:273`；`docs/对齐说明-与2026-10-01自举方案.md:28-29`）。

## 2. 谁维护

| 角色 | 能做什么 | 不能做什么 |
|---|---|---|
| **Peter（人）** | 新增/修改/删除用例；签署 `ratified_by`；裁定冲突 | —— |
| **REVIEWER（异源 agent/人）** | 只读；可提交"提议新增"（作为 Issue/PR 评论，不直接改文件） | 改真值库本身 |
| **CODER / PLANNER（agent）** | 只读；跑 `eval/runner` 生成观测 | 改用例、改 `expect_behavior`、改状态判定标准 |
| **harness（代码）** | **只读** + 只追加运行产物（`eval/results/<run_id>.json`） | 写 `cases.jsonl` |

硬红线（吸收自 `docs/VSL-v3-验证标准层.md:148-149`）：

> 防止"同一智能体同时改实现、预期答案和放行标准"。
> **用例集、判分器、红线清单三者是只读资产，改动需升版并经人批准。**

同一来源的 `docs/代码与版本管理方案-v0.md:80` 明确：冲突落在**判分器/金标准集**时**由人裁决**，且必须升版 + 保留旧哈希。

### 2.1 种子条目（本文件当前状态）

`cases.jsonl` 目前是 **agent 起草的种子**。每条 `added_by` 记录了起草者、`ratified_by` 为 `null`。
**未获 Peter `ratified_by` 签署的条目，是"待批提案"，不是正式真值。** 它们可以被跑、被观测，但不得被用来宣称能力通过（`docs/VSL-v3-验证标准层.md:122` 要求 `met` 需 approver 已签）。

## 3. 增删改流程

```
提议（任何人/agent，走 Issue 或 PR 评论，写明 source + 实测出处）
   ↓
异源复核（REVIEWER：这条 expect_behavior 是否可判定、counterexample 是否真能证伪）
   ↓
Peter 批准 + 签署 ratified_by/ratified_at（人）
   ↓
合并进 cases.jsonl（append；修改旧条目 = 升版并保留旧哈希）
   ↓
下次 runner 运行自动复算 status，绑定四元组
```

### 3.1 新增（append-only）

- 每条必须有 `source` 与 `evidence_ref`（`文件:行号`），且该出处**真实存在、可重新打开**（`docs/VSL-v3-验证标准层.md:73` V3-04）。
- `expect_behavior` 必须是**可判定陈述**：谓词 + 对象 + 条件；禁止形容词（"稳定/好/快"）；判据锚定**外部产物**（回执/落盘文件/HTTP 响应），**不锚退出码、不锚 agent 自述**（`docs/长城任务-预注册与台账规范-v0.md:115`）。
- `forbidden_behavior` 写"绝对不许发生什么"，且必须是**可观测**的（如"不得产生删除副作用"）。
- 禁止"空壳用例/合成题满分/单纯 JSON 合法"加分项（`docs/长城任务-预注册与台账规范-v0.md:81` 反博弈清单）。

### 3.2 修改（禁止回溯改判）

- **已合并条目的判定标准不得就地修改**。要么新增 supersede 条目、要么整体升版并保留旧版哈希与旧判定（`docs/VSL-v3-验证标准层.md:131-132`；`docs/代码与版本管理方案-v0.md:80`）。
- **禁止本次变更自行降低门槛**（`...自举方案.html` 引用的 `CICD-BOUNDARY-001:107`）：验证标准属于"变更前可信策略"。
- 历史判定**不得回溯修改**（`fr-25` 反博弈要求）。

### 3.3 删除

- 只能**标记失效**（置一个显式废弃字段），不得物理删除历史条目——删除会销毁"曾经判错过"的证据。
- 删除/失效同样需要 Peter 签署。

### 3.4 契约变更联动

契约变更必须**伴随** `eval/cases.jsonl` 用例更新（`docs/对齐说明-与2026-10-01自举方案.md:60`）。
"改了契约但没动用例"本身视为缺一项验收证据。

## 4. 为什么 harness 只能读不能写

三个独立理由，任一成立即足够：

1. **组织结构**：真值库是**外部真理源**。写者与判分者分离，才能"从机制上打断自我强化"（`...自举方案.html:273`）。
2. **防自欺铁律**：「**自产不能自证**：agent 产出的东西（测试、标准、结论）不得作为它自己合格的证据」（`docs/人机校准节拍-v0.md:96`）。
3. **可观测性幻觉**：trace 视觉连贯 ≠ 语义正确；"可观测性仅放大了问题可见性，却未赋予判断力"（`docs/人机校准节拍-v0.md:23`）。让被测方写预期，等于用它的叙事替代真实工作。

实现约束：`eval/runner/runner.go:10` 的运行规则要求"**冻结输出先行**：先落盘原始观测，再算分；冻结输出不可回改"。即 runner 只能**追加**观测，不能回写用例。

## 5. "未评测"如何显式保留

### 5.1 三态定义（`status`）

| 取值 | 含义 | 触发条件（吸收 `docs/VSL-v3-验证标准层.md:119-126`） |
|---|---|---|
| `met` | 判据满足 | 有可复算证据；证据等级 ≥ E2；`ratified_by` 已签 |
| `not_met` | 判据被反例证伪 | 实测观测与 `expect_behavior` 冲突 |
| `unverified` | **未验证（合法结论）** | ①阈值 `unset` ②证据等级 E0/E1 ③样本不足 ④该路径本轮未跑 |

### 5.2 四条硬规则

1. **`unverified` 不得折算为通过，也不得折算为 0 分**——必须原样显性存在（`docs/VSL-v3-验证标准层.md:130`；`docs/人机校准节拍-v0.md:53`）。
2. **分数必带分母**：任何分数必须报"评了几条 / 未评测几条"（`docs/人机校准节拍-v0.md:98`；`:111` 的 `分母` 字段）。
3. **观察不足 ≠ 通过**：低流量下的"没有错误"可能只是"没有样本"（`docs/人机校准节拍-v0.md:25` 引 `CICD-BOUNDARY-001:389`）。
4. **单一内部信号不得触发结论**：结论至少要**一个外部锚点**参与（`docs/人机校准节拍-v0.md:99`）。

### 5.3 落地要求

- 统计一律输出为 `met / not_met / unverified` **三列各自计数 + 总分母**，禁止只报一个"通过率"。
- 报告里必须有一节固定的「**未验证项显式保留**」（见 `eval/review/REVIEW-PROTOCOL.md` 的结果模板）。
- 版本绑定：一次运行必须带完整四元组
  `{commit_sha, rubric_hash, prereg_hash, model_version}`；
  **四元组不完整，本次运行的任何结论都不得作为依据**（`eval/runner/runner.go:11-12,27-35`；`docs/人机校准节拍-v0.md:108`；`docs/代码与版本管理方案-v0.md:100-102`）。

## 6. 字段规范（`cases.jsonl`，每行一个 JSON 对象）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 全局唯一，建议 `VHS-ASR-NNNN` |
| `source` | ✅ | 该行为的**实测来源**（测试函数名 / 文档小节） |
| `raw_text` | ✅ | 喂给管线的 ASR 文本（空串也合法，表示"没听清"） |
| `context` | ✅ | 运行条件、变体、复现命令、本轮观测值 |
| `expect_behavior` | ✅ | **可判定**陈述：应发生什么 |
| `forbidden_behavior` | ✅ | **绝对不许发生什么**（可观测） |
| `evidence_ref` | ✅ | `文件:行号`，必须真实存在 |
| `status` | ✅ | `met` / `unverified` / `not_met` |
| `added_by` | ✅ | 起草者（人 = `Peter`；agent = `dsh-agent(seed)`） |
| `added_at` | ✅ | `YYYY-MM-DD` |
| `observed_at_commit` | 建议 | 本条 `status` 对应的 commit（短 sha）；未观测填 `"unobserved"` |
| `verify_cmd` | 建议 | 可复制复算命令 |
| `ratified_by` | ✅ | 人签署者；**`null` = 未获人工批准，仅种子** |
| `ratified_at` | ✅ | 同上；未批准为 `null` |

**禁止**在用例里放原始隐私素材：只入脱敏后的任务定义，原始件不入 Git（`docs/人机校准节拍-v0.md:38`）。
