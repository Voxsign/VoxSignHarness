# VHS-COG · 认知能力线（长期常设，非一次性任务）

> **定位**：这不是一个任务，是**一条长期能力线**。与 `ASR 个性化识别` 并列，长期投入、持续评测。
> **提出**：Peter，2026-10-03
> **原话要点**：「形成一个长期的、持续的能力……**集中精力把它做成规划线**……
> 把这个做成一个技术——**我认识世界是要对这个世界建立一个模型的**。
> 把 peterzou.com 上所有关于**认知能力 / 规划能力 / 模型怎么认识的**文章先读一下，
> **重新再思考怎么放到这里面来实现**。」
>
> **性质**：DSH 出设计与判据；实现由 voice-sign harness 侧落地。

---

## 1. 为什么它必须是"线"而不是"任务"

我在第 17 轮如实回答过：**它没有世界模型，也没有学习回路。**

本轮实测出的四条缺口，**全是同一个洞**：

| 实测现象 | 缺失的东西 |
|---|---|
| `如果测试通过就提交` → **无条件执行** | **不知道前提**（没有状态模型） |
| `查库存，然后记结果，最后提交` → **只做第一件** | **不知道自己在多步任务的哪一步** |
| `注册一个命令` → UNKNOWN（`加一个工具`却行） | **不知道自己能力的边界在哪** |
| 几十次纠正 → **系统一件没学到** | **不知道用户说错了** |

**这四条不会因为"修完 G1–G9"而消失**——它们是**结构性缺陷**。
打补丁能让某句话判对，**不能让系统获得"知道"的能力**。

所以：**建成一条线，长期做，持续评测。**

## 2. 你的研究如何直接落到这个架构上

### 2.1 《LLM 并非真正的世界模型》→ 世界的模型必须在**架构里**，不在模型里

文章的核心判断：

> LLM 是「**被校准过的统计预测器**」，缺乏**因果完整性与状态演化闭包**；
> 同一实体在不同时间步表征偏差显著，**不满足时不变性**；
> RLHF/DPO 只是**输出分布层面的外挂校准**，未修正底层递归逻辑。
>
> **可迁移结论**：「LLM 的**权限边界在于其统计自洽性**，而非对复杂因果链条的掌控。
> 为弥补世界模型的缺失，需要在**系统架构**中引入更显式的反馈回路与交叉验证。」

**→ 落地方案：世界模型由本机显式持有，模型只做仲裁。**

| 世界的哪一部分 | 谁持有 | 为什么不能交给模型 |
|---|---|---|
| **自身**：我能做什么、不能做什么 | **本机**（能力清单，从代码导出） | 模型会**虚报**能力（幻觉出没有的工具） |
| **世界**：域、项目、文件、权限 | **本机**（space/ground） | 这是"当前事实"，模型没有 |
| **历史**：做过什么、结果如何、用户怎么纠正的 | **本机**（轨迹 + 决策日志） | 模型**无跨会话记忆**，且表征不满足时不变性 |
| **推理**：给定这些，下一步该做什么 | **外部模型** | 这是通用推理，外置才有复利 |

> **一句话**：**事实在本机，推理在外**。这与「能力外置，本机极简」不矛盾——
> 外置的是**能力**，本机保留的是**关于自己的事实**。

### 2.2 《自主决策失效迷宫》→ 分层混合架构，正是本项目的形状

文章的失效模式与我们的实测**逐一对应**：

| 文章说的失效 | 我们的实测 |
|---|---|
| **路径幻觉** | `如果测试通过就提交` → 直接执行（忽略了前提） |
| **过早判 Done** | 多动作只做第一件，其余静默消失 |
| **意图漂移** | `开始测试` 被当成"跑 go test"（对话控制 → 执行命令） |
| **协调熵** | 9 条缺口彼此纠缠（否定 × 元指令 × 条件 × 多动作 × 修正） |

文章给的架构——**「静态规则作为高危边界的护栏，动态语义仲裁处理模糊边界」**——
**就是我们这一轮实际收敛到的形状**：

```
护栏（本机规则，不可协商）      仲裁（外部模型，处理模糊）
  · 域门禁：默认拒绝              · 意图歧义：回问或模型判
  · 不可逆必须人工                · 指代不清：三层消解
  · 否定/条件/元指令 → 绝不执行    · 规划：给定边界内组合
```

**关键领悟**：我前面修 G1–G9 时一直在**用规则去处理模糊边界**——那是错的方向。
正确做法是**规则只管护栏，模糊的交出去**。这也解释了为什么我每修一条就要立一条新守卫：
**我把仲裁的活派给了规则。**

## 3. 四个可测维度（这条线的"仪表盘"）

| 维度 | 测什么 | 真值来源 | 现状 |
|---|---|---|---|
| **D1 意图识别** | 这句话要做什么 | 人工标注语料 | 20/20（但**语料是我造的**，说服力有限） |
| **D2 目标识别** | 说这句话**想达成什么**（可含多步） | 人工标注 + 上下文 | **未测**（多动作即是失败案例） |
| **D3 规划** | 给定目标，能否产出可执行步骤 | 能力清单（**可从代码导出**） | **完全没有** |
| **D4 自我认识** | 它对自己的描述**是否等于真值** | 工具注册表（**客观**） | **完全没有** |

> **D4 是这条线的入口**，因为它是**唯一有客观真值、可以完全机械判定**的维度。
> 一个连自己有什么工具都说不准的系统，谈规划没有意义。

**判据见 `VHS-PLAN-001`（SK-1..4 / PL-1..5 / RV-1..4），本文不重复。**

## 4. 这条线怎么"长期做"

### 4.1 常设判据（永久存在，先红）
SK / PL / RV 三组判据写进 `-tags vhscog`，与 `asrharness`、`vhs002` 并列。
**红是常态**——它标的是"这条线离目标还有多远"，不是"这次提交坏了"。

### 4.2 定期评测（可比较，才叫长期）
- **同一批语料**：意图/目标/规划三类，语料**随真实使用增长**
- **同一个模型**：按 `ASR-MODEL-01`，**模型固定**，否则进步归因不到架构
- **每次评测带四元组**：`{commit, 判据哈希, 语料哈希, 模型版本}`——与本项目既有结算口径一致
- **节拍**：每完成一条能力，跑一次全量，出趋势

### 4.3 版本化演进
- 判据改动 = **升版 + 说明"旧判据测错了什么"**（本会话已用过 5 次，含 4 次是我自己的错）
- 语料只增不删，**标注来源**（`observed` / `constructed`）

### 4.4 "越用越准"必须可测量
这是你反复强调的。可测量的形式：

```
同一批语料 → 第 N 周的正确率
真实使用 → 每周新增的 observed 语料
反馈闭环 → 用户纠正后，同类输入**下次是否判对**（这才是"学到"的定义）
```

> **第三条是真正的试金石**：不是"模型变强了"，是"**上次错的那类，这次对了**"。

## 5. 落地顺序（先立仪表盘，再补能力）

| 阶段 | 做什么 | 为什么这个顺序 |
|---|---|---|
| **C0** | 立 D4（自我认识）判据 —— 与注册表双向对账 | **唯一有客观真值的入口**，先证明"它知道自己" |
| **C1** | 立 D3（规划）判据 —— 可达/不可达/多步/失败复规 | 在 C0 的边界内规划 |
| **C2** | 能力清单从代码**机械导出** | 让 C0 的判据自动化，不靠手写文档 |
| **C3** | 规划器接外部模型（模型固定） | 边界已立，才敢让模型进来 |
| **C4** | D2 目标识别：多步目标 → 计划 → 执行 | 多动作静默丢弃的病根在此 |
| **C5** | **反馈闭环**：用户纠正 → 写回 → 下次判对 | 你反复强调的"越用越准" |

**C0–C2 不需要模型**，可以立刻做，且**全部应当先红**。

## 6. 诚实边界

- 我**读了 2 篇**（《LLM 并非真正的世界模型》《自主决策失效迷宫》），
  **其余相关文章（认知外化的边界、可证伪的行为契约、复杂决策五大原理的边界等）未读**。
  引用的是正文，但**没有独立验证文中数据与文献**——文章自己也标了"数据须独立验证"。
- **"世界模型"在本设计中是工程意义上的**：一组本机持有的、可查询、可对账的事实。
  **不是**认知科学意义上的世界模型。**不要把这个词当成已达成的成就。**
- D4 的"客观真值"是**工具注册表**——它客观，但**只覆盖工具与意图**，
  不覆盖"我理解得对不对"。后者仍需要人判。
- 这条线**未覆盖**：跨会话长期目标、多目标冲突、目标分解深度控制、规划的时间成本。
- 本文件是**设计**，零实现。**判据先红是预期状态。**
